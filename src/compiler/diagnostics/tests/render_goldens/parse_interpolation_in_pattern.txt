-- A MALFORMED STRING INTERPOLATION ------------------------ test.ipe

A pattern matches a fixed string, so it can't interpolate a value. A `{{…}}` in a `"""` string holds one expression, and the first `}}` after the `{{` ends it.

 --> test.ipe:5:13
  |
5 |         """x{{y}}""" ->
  |             ^^^^^ an interpolation in a pattern
  |
  = help: compare the string with `==` instead, or write `\{{` for a literal `{{`
