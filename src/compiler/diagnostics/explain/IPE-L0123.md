# IPE-L0123: `Web.route` page builder is not a bare page constructor

The second argument to `Web.route` must be a constructor of the app's page
type, named on its own, e.g. `DashboardPage` or `AppDetailPage` when
`type Page = AppDetailPage String | ...`. The route's `:param` segments fill
the constructor's payload fields in order.

The compiler derives two functions from the route table: one that parses a
path into a page, and its inverse, which renders a page back into its
canonical path. A constructor has an inverse; a function does not. So a
lambda, a named or let-bound function, and a partially applied constructor
are refused as builders.

A lambda builder is refused — it has no inverse, so the page's path cannot be
rendered:

```ipe ipe:error
module Main exposing (main)

import Ipe.String as String
import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = AppDetailPage String

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = AppDetailPage "x" }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view model =
    case model.page of
        AppDetailPage id ->
            Ui.text (String.toUpper id)

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes =
            [ Web.route "/apps/:id" (\id -> AppDetailPage (String.toUpper id)) ]   -- ✘ a lambda has no inverse
        , notFound = AppDetailPage "none"
        }
```

A named function is refused for the same reason:

```ipe ipe:error
module Main exposing (main)

import Ipe.String as String
import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = AppDetailPage String

type alias Model = { page : Page }

type Msg = NoOp

buildApp : String -> Page
buildApp id =
    AppDetailPage (String.toUpper id)

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = AppDetailPage "x" }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view model =
    case model.page of
        AppDetailPage id ->
            Ui.text (String.toUpper id)

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/apps/:id" buildApp ]   -- ✘ a named function is refused for the same reason
        , notFound = AppDetailPage "none"
        }
```

Pass the constructor and reshape the parameter where it is used:

```ipe ipe:skip a fragment; route, AppDetailPage, and model are assumed from context
-- ✔ The constructor itself.
routes = [ route "/apps/:id" AppDetailPage ]

-- Reshape in `view` (or `update`), not in the builder.
view model =
    case model.page of
        AppDetailPage id -> Html.text (String.toUpper id)
```

Each payload field must be a type a URL segment can carry: `String`, `Int`,
`Float`, or `Bool`.

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = TagsPage (List String) | HomePage

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view model =
    case model.page of
        TagsPage _tags ->
            Ui.text "tags"

        HomePage ->
            Ui.text "home"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes =
            [ Web.route "/tags/:tags" TagsPage   -- ✘ a `List String` payload cannot be filled from one path segment
            , Web.route "/" HomePage
            ]
        , notFound = HomePage
        }
```

constructor's payload.
