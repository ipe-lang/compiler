# IPE-P0077: a malformed string interpolation

A `{{…}}` inside a `"""` string interpolates one expression: the compiler
reads the text between `{{` and the first `}}` after it with the same lexer
and parser as any other code, then shows the value in the string. Any
expression may stand there — a name, a call, an operator chain, a field
access — as long as the whole body is that one expression.

An interpolation is refused when its body is not exactly one expression:
it is empty, it holds more tokens after a complete expression, or the first
`}}` cuts the expression short. Here the first `}}` closes the
interpolation inside the record literal, so `{ a = { b = 1` is all the body
holds:

```ipe ipe:error
nested : String
nested =
    """value {{ { a = { b = 1 }} }}"""
```

Bind the expression to a name and interpolate the name; the body then ends
at the `}}` you meant:

```ipe
nested : String
nested =
    let
        record =
            { a = { b = 1 } }
    in
    """value {{ String.fromInt record.a.b }}"""
```

A call or an operator chain needs no binding:

```ipe
summary : List Int -> String
summary shapes =
    """{{ String.fromInt (List.length shapes) }} shapes"""
```

A `{{` with no `}}` after it in the string is refused too. Write `\{{` for a
literal `{{`, which stays text:

```ipe
template : String
template =
    """use \{{name}} to interpolate"""
```

A string with an interpolation can't stand where a pattern is expected: a
pattern matches a fixed string. Compare the value with `==` instead.
