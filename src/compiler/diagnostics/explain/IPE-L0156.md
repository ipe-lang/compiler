# IPE-L0156: a literal route pattern or server route path is malformed

A `Web.route` pattern and the path of a `Server.*` route (`Server.get`,
`Server.post`, `Server.api`, …) follow one grammar, the same one the runtime
checks before it serves a request; mount prefixes have their own, below:

- A parameter segment is `:name`. The name is a letter or `_` followed by
  letters, digits, or `_`: `[A-Za-z_][A-Za-z0-9_]*`. A server route has no
  `*name` catch-all, and the parameters of one path are bounded in number.
- Every parameter in one path has a distinct name.
- A literal segment is strictly percent-decodable:
  each `%` starts an escape of two hex digits, and the decoded bytes are valid
  UTF-8.

When the path is a string literal, `ipe` refuses a path that breaks the grammar
at compile time, so the program never starts with a route table the runtime
would turn back.

A parameter name must be an identifier:

```ipe ipe:error
-- ✘ `-` is not allowed in a parameter name.
routes = [ route "/posts/:post-id" PostPage, ... ]

-- ✔
routes = [ route "/posts/:post_id" PostPage, ... ]
```

A parameter needs a name, and each name appears once per path:

```ipe ipe:error
-- ✘ No name after `:`.
routes = [ route "/posts/:" PostPage, ... ]

-- ✘ `id` names two segments.
routes = [ route "/users/:id/posts/:id" UserPostPage, ... ]

-- ✔
routes = [ route "/users/:user_id/posts/:post_id" UserPostPage, ... ]
```

A `%` in a `Web.route` literal segment starts a two-hex-digit escape of UTF-8
bytes:

```ipe ipe:error
-- ✘ `%zz` is not an escape.
routes = [ route "/files/100%zz" FilesPage, ... ]

-- ✔ `%25` is a literal percent sign.
routes = [ route "/files/100%25" FilesPage, ... ]
```

In a routed app (its Model has a `page` field), every page's path is rendered
back into a URL, and a browser drops an empty, `.` or `..` segment. A literal
segment that is empty or decodes to `.` or `..` is refused:

```ipe ipe:error
-- ✘ `//` leaves an empty segment, and `%2E%2E` decodes to `..`.
routes = [ route "/docs//intro" IntroPage, route "/docs/%2E%2E" UpPage ]

-- ✔
routes = [ route "/docs/intro" IntroPage, route "/docs/up" UpPage ]
```

A server route path starts with `/`, matches a fixed number of segments, and
takes a parameter only as a whole segment led by `:`:

```ipe ipe:error
import Ipe.Http.Server as Server
import Ipe.Task

-- ✘ No leading `/`; `*rest` is a catch-all; `:` inside `v-:id`.
-- ✔ Write `/health`, `/files/:dir/:name` and `/v/:id`.
main =
    Server.listen 8000
        [ Server.get "health" (\_ -> Task.succeed (Server.text "ok"))
        , Server.get "/files/*rest" (\_ -> Task.succeed (Server.text "file"))
        , Server.get "/v-:id" (\_ -> Task.succeed (Server.text "v"))
        ]
```

A `Server.api` spec that names a method names one the server serves: `GET`,
`HEAD`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`, `CONNECT`, `TRACE` or
`ANY`, in any ASCII case. A spec with no method serves every method:

```ipe ipe:error
import Ipe.Http.Server as Server
import Ipe.Task

-- ✘ `FETCH` is no method the server serves.
-- ✔ Write `Server.api "GET /items"`, or `Server.api "/items"`.
main =
    Server.listen 8000
        [ Server.api "FETCH /items" (\_ -> Task.succeed (Server.text "items")) ]
```

A `Server.static` or `Server.mountApp` prefix is a string literal, so it is
checked when the program compiles. It is `/`, or `/`-separated segments of the
letters, digits, `-`, `.`, `_` and `~`, with no empty, `.` or `..` segment and
no trailing `/`. No two mounts share a prefix; a longer prefix nested under
another is served by the longer one:

```ipe ipe:error
import Ipe.Http.Server as Server
import Ipe.Task

-- ✘ `%` and a trailing `/` break the prefix grammar; `/assets` is mounted
--   twice.
-- ✔ Write `/files`, `/assets` once, and `/assets/v2` for a nested mount.
main =
    Server.listen 8000
        [ Server.static "/files%20" "public"
        , Server.static "/docs/" "docs"
        , Server.static "/assets" "public"
        , Server.static "/assets" "other"
        ]
```
