# IPE-E0007: the project names no entry module

A project builds either programs or a library. ipe finds the programs in
`package.ipe`'s `programs` list, or, when there is none, in the default entry
`src/Main.ipe`; it finds a library's modules in `exposedModules`. This project
has none of the three, so there is nothing to build.

What to try (either fix is enough):

1. **Create `src/Main.ipe`**, the default entry module.
2. **Declare the entry in `package.ipe`**, relative to `src/`:
   `programs = [ { name = "app", entry = "App.ipe" } ]`.

A library instead lists its public modules in `exposedModules`.

The smallest default entry, `src/Main.ipe`, is:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

An entry may define values beside `main`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And it may import from the standard library:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
