# IPE-T0018: this catch-all arm hides constructors of a closed union

Your `case` uses a catch-all arm — a wildcard `_` or a bare variable binder like
`other` — over a **closed union**: a type whose full set of constructors the
compiler knows. The catch-all silently swallows one or more constructors that no
earlier arm named.

The code examples below are illustrative Ipê source snippets, not shell commands.

This is an **error**: a closed union's variants must each be handled. The reason
is what happens next time someone adds a variant to the type. With every
constructor listed explicitly, the compiler flags every `case` that needs
updating. With a catch-all, the new variant falls through silently, inheriting
whatever the `_` arm does — which is almost certainly wrong. Ipê forbids the
catch-all so that a silently-swallowed new variant is not even representable.

Here `Shape` has three constructors, two are listed, and `_` silently absorbs
`Triangle`:

```ipe ipe:error
type Shape
    = Circle
    | Square
    | Triangle

describe : Shape -> String
describe shape =
    case shape of
        Circle ->
            "a round shape"

        Square ->
            "a four-sided shape"

        _ ->
            "some other shape"
```

Handle each remaining constructor with its own arm, so every future addition is
caught at this site:

```ipe
type Shape
    = Circle
    | Square
    | Triangle

describe : Shape -> String
describe shape =
    case shape of
        Circle ->
            "a round shape"

        Square ->
            "a four-sided shape"

        Triangle ->
            "a three-sided shape"
```

The error names every absorbed constructor, so expanding the catch-all into one
arm per named constructor — each carrying the catch-all's original body — is a
mechanical edit.

## Which types this applies to

The rule fires only for a **closed, user-evolvable union** — a `type` you
declared, or a Prelude built-in union like `Maybe` or `Result`. So
`case m of Just x -> …; _ -> …` (the `_` absorbing `Nothing`) is an error: the
set `{ Just, Nothing }` is finite and stable, and a catch-all over it is exactly
the silent fall-through this rule targets.

These types are **not** affected, so a catch-all over them keeps compiling:

- **`Bool`** and **`List`** — closed, but their variant set is frozen by the
  language: no one will ever add a variant to `Bool` or `List`. So
  `case xs of [] -> …; _ -> …` is a safe idiom (the `_` means "cons", never "a
  future variant"), and it compiles.
- **`Int`, `Float`, `Char`, `String`** — open (infinite) domains. A catch-all is
  *required* for exhaustiveness and is never an error.

## Grouping variants that share a body

When several constructors should share one body, group them explicitly with an
**or-pattern** (`A | B ->`) instead of reaching for `_`. The group is checked
against the union, so a later-added variant it does not name is still flagged —
you keep the "handled once" convenience without the silent fall-through:

```ipe
describe : Shape -> String
describe shape =
    case shape of
        Circle | Square ->
            "a straightforward shape"

        Triangle ->
            "a three-sided shape"
```

## Deferring variants during development

While a type is still growing, a bare `_` is inconvenient — but so is spelling
out arms you have not designed yet. Use the development-only catch-all
**`Debug._`**:

```ipe
describe : Shape -> String
describe shape =
    case shape of
        Circle ->
            "a round shape"

        Debug._ ->
            "not designed yet"
```

`Debug._` matches every remaining value like `_`, but is *exempt* from this
rule, so `ipe dev build` / `ipe dev run` accept it. Like every other `Ipe.Debug`
member it is a development-only escape hatch: **`ipe release` rejects it**
(IPE-L0140). It is a deliberate, visible marker of an unfinished `case`, never a
way to ship a silent default.

## Judged from the scrutinee's type

The rule identifies the union from the scrutinee's **inferred type**, so it fires
whether or not a constructor arm precedes the catch-all. A `case` whose *only*
arm is a bare catch-all over a closed union —

```ipe ipe:error
name : Color -> String
name c =
    case c of
        _ ->
            "other"
```

— is rejected too, naming every variant the `_` would absorb. Closed-union
catch-alls are rejected universally; the only sanctioned catch-all over a closed
union is the development-only `Debug._` above.
