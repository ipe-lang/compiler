# IPE-P0040: only a type constructor can take arguments

In a type, I found something being applied to arguments that isn't a
type constructor. Only a named type — like `List`, `Maybe`, or one you
declared — can be followed by argument types (`List Int`, `Maybe
String`). A type variable, a record, or a parenthesised type can't take
arguments that way.

This usually means an argument wandered next to the wrong thing, or a
lowercase type variable was treated as if it were a constructor. Type
variables stand on their own; constructors are the only part of a type
that "applies" to others.

Applying arguments to a type variable isn't allowed:

```ipe ipe:error
get : a Int -> a
```

If you meant a real container, name the constructor that takes the
argument:

```ipe
get : List Int -> Int
get xs =
    0
```

And a type variable used plainly, with no arguments, is fine:

```ipe
identity : a -> a
identity x =
    x
```
