# IPE-N0023: module path mismatch

The `module` declaration at the top of a `.ipe` file does not match the file's location under the project's `source_root`. I derive the expected module name from the file path, and they must agree.

A file located at `src/Lib/Utils.ipe` must begin with:

```ipe ipe:skip the checker places a block's scratch file at the path its own header names, so it can never construct a header/path disagreement
module Lib.Utils exposing (..)
```

If instead it says:

```ipe ipe:skip the checker places a block's scratch file at the path its own header names, so it can never construct a header/path disagreement
module Util exposing (..)
```

I cannot figure out which name is authoritative. The file path and the module header must always match.

Another example — a file at `src/Api/Handlers/Auth.ipe`:

```ipe ipe:skip the checker places a block's scratch file at the path its own header names, so it can never construct a header/path disagreement
-- Wrong: does not match the path
module Auth exposing (login, register)
```

```ipe
module Api.Handlers.Auth exposing (login, register)

login : String
login =
    "login"

register : String
register =
    "register"
```

To fix this error, make the `module` declaration match the directory structure. Each `/` in the path becomes a `.` in the module name, and each path segment must be capitalised exactly as the directory or file name.

If your source root (`Package.sourceRoot` in `package.ipe`) is `src/`, the segment list starts one level below that. So `src/Data/Model.ipe` → module `Data.Model`.
