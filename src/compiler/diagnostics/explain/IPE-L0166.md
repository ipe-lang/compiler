# IPE-L0166: a `Web.pageLink` table is not the routed app's `routes` binding

A routed app writes the address bar from its `routes`, and every
`Web.pageLink` writes its `href` from its own table. Both must be the same
table, so a link always names the address the app shows for that page. The
compiler checks this by name: the app's `routes` and every page link name one
top-level value.

An inline `routes` list beside a page link names no value, so it is refused:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage

type alias Model = { page : Page }

type Msg = NoOp

appRoutes : List (WebRoute Page)
appRoutes =
    [ Web.route "/" HomePage, Web.route "/about" AboutPage ]

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view model =
    Web.pageLink appRoutes [] { to = AboutPage, current = model.page, label = Ui.text "About" }

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage, Web.route "/about" AboutPage ]   -- ✘ not `appRoutes`.
        , notFound = HomePage
        }
```

Two page links that name two different tables are refused the same way.

Name the routes once and use that name in both places:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage

type alias Model = { page : Page }

type Msg = NoOp

appRoutes : List (WebRoute Page)
appRoutes =
    [ Web.route "/" HomePage, Web.route "/about" AboutPage ]

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view model =
    Web.pageLink appRoutes [] { to = AboutPage, current = model.page, label = Ui.text "About" }

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = appRoutes   -- ✔ the same table the link names.
        , notFound = HomePage
        }
```
