# IPE-P0031: malformed type declaration

I was reading a type declaration and it doesn't hold together. A custom
type introduces a new name with `type`, then `=`, then one or more
constructors separated by `|`; a type alias uses `type alias Name =`
followed by the type it stands for. Something in that shape is missing
or out of place here.

Look for the usual gaps: a missing `=`, an empty side after a `|`, a
constructor that starts with a lowercase letter (constructor names must
be capitalised), or an alias with no body after its `=`. The caret
marks where the declaration stopped making sense.

A dangling `|` with no constructor after it is malformed:

```ipe ipe:error
type Direction =
    North | South |
other = 2
```

Give each `|` a constructor, and stop at the last one:

```ipe
type Direction
    = North
    | South
    | East
    | West
```

A type alias must name the type it abbreviates after its `=`:

```ipe
type alias Point =
    { x : Int, y : Int }
```
