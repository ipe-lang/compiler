# IPE-N0020: module not found

You wrote an `import` for a module that I could not find. I looked through every `.ipe` file under the project's `src/` directory, and none of them declares the module name you imported.

This is almost always a typo, a missing file, or a case where the module name does not match the file path. If the name is close to something I do know about, I will suggest it.

If the module lives in a library you declared in `dependencies`, you see `dependency-not-compiled` instead of this error: no dependency is compiled yet, so a package that declares one is refused before any import is resolved. Copy the library's modules into this package's `src/` and remove it from `dependencies`.

Here a module name is misspelled in an import:

```ipe ipe:skip
module Main exposing (main)
import Lib.Utlis as Utils

main = println (String.fromInt (Utils.add 1 2))
```

There is no module `Lib.Utlis`. If you meant `Lib.Utils`, create `src/Lib/Utils.ipe` and make sure its header declares `module Lib.Utils exposing (..)`.

A correctly spelled import that matches an existing file:

```ipe ipe:skip
module Main exposing (main)
import Lib.Utils as Utils

main = println (String.fromInt (Utils.add 1 2))
```

If the file exists but still produces this error, check that the `module` declaration at the top of the file matches its path under `src/`. For example, `src/Lib/Utils.ipe` must begin with `module Lib.Utils`.

Here is what `src/Lib/Utils.ipe` should look like:

```ipe ipe:skip
module Lib.Utils exposing (add)

add : Int -> Int -> Int
add x y = x + y
```
