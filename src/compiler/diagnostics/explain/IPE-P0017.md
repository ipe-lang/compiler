# IPE-P0017: unterminated block comment

I started reading a block comment at `{-` but reached the end of the
file before finding the matching `-}` that closes it. A block comment
must always be properly closed — a `{-` with no `-}` makes it
impossible to know whether the rest of the source is a comment or real
code.

Ipe block comments can nest, which means each `{-` inside a comment
requires its own `-}` to close it. If you open two comments you must
close two:

```ipe
{- this is a comment
   {- this nested comment needs its own close -}
   back in the outer comment
-}
```

A comment whose `-}` is missing lands here:

```ipe ipe:error
{- this comment starts fine
   but never ends ...
```

Adding the closing `-}` fixes it:

```ipe
{- this comment starts fine
   and now it ends correctly -}
value = 0
```

If you have a nested `{-` remember you also need a matching `-}` for
it — counting unmatched `{-` and `-}` pairs can help locate the
missing close:

```ipe
{- outer start
   {- inner start
   inner end -}
outer end -}
value = 0
```
