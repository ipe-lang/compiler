# IPE-N0001: cannot find this value in scope

You used a value by name, but I could not find anything with that name where you used it. I looked through the constructors, the local bindings, the top-level definitions in this module, and the built-in kernel values — and none of them matched.

This is almost always a typo or a name that has not been brought into scope yet. If the name is close to something I do know about, I will suggest it. Watch out for one common case: a name can exist in a different namespace (a type or a constructor) and still not be usable as a plain value — when that happens I will point it out.

Here a value name is misspelled:

```ipe ipe:error
import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task Error ()
main =
    Io.println greetng
```

I cannot find `greetng`. You almost certainly meant `greeting`:

```ipe
import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task Error ()
main =
    Io.println greeting
```

Another frequent cause is using a name before you have defined it anywhere in the module. Define it as a top-level binding (or a `let`), then refer to it:

```ipe
total : Int
total = price + tax

price : Int
price = 100

tax : Int
tax = 7
```
