# IPE-S0004: the control model is not covered by acceptsControl

Your `package.ipe` opted into control-model consent by declaring
`acceptsControl`, but the control model your program actually runs under is not
in that list. A program's control model — how it drives itself — is derived by
the compiler from the shape of `main`: `Tea` for a managed program that runs
under the runtime's own loop, `Direct` for a program that runs its own task and
drives itself. Once you declare `acceptsControl`, the list is authoritative: it
must cover the model the program really has, so a stale acceptance cannot
certify a package whose entry changed after you reviewed it.

An empty or absent `acceptsControl` never triggers this: the model is then
disclosed but not gated, and a plain `Direct` script certifies as it is.

## The safe path is untouched

A program whose control model is covered, or one that never declared
`acceptsControl`, gets no refusal. A managed program is ordinary Ipê:

```ipe
import Ipe.Html exposing (text, section)

view summary =
    section [] [ text summary ]  -- no manifest opt-in: nothing to cover
```

## What triggers the refusal

The declared set omits the model the entry runs under. Here the package pinned
`Tea`, and the entry now runs a `Direct` task:

```ipe ipe:skip a manifest fragment, shown for its shape
-- package.ipe
-- package =
--     { name = "my-app"
--     , capabilities = { acceptsControl = [ Tea ] }
--     }
```

## How to fix it

Review the entry's control model, then add the constructor the refusal names to
`acceptsControl`, or switch the entry back to a listed model:

```ipe ipe:skip a manifest fragment, shown for its shape
-- package.ipe
-- package =
--     { name = "my-app"
--     , capabilities = { acceptsControl = [ Tea, Direct ] }
--     }
```

## Glossary

- **control model** — how a program drives itself: `Tea` (managed by the
  runtime's loop) or `Direct` (the program runs its own task).
- **stale acceptance** — a declared set that no longer covers the program it
  was written for.
- **fail closed** — when the declared set does not cover the program, refuse
  rather than certify.
