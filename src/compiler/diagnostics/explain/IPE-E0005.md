# IPE-E0005: the project has no src directory

Every project keeps its modules in a `src/` directory beside `package.ipe`.
The project directory has a manifest but no `src/` directory, so there is no
module to compile.

A `src` that is a symbolic link counts as missing too: ipe opens the project's
directories without following links, so the sources it reads are always the
ones inside the project, never a tree a link points somewhere else.

What to try:

1. **Create `src/`** beside `package.ipe` and move your modules into it.
2. If `src` is a symbolic link, **replace it with the real directory**.

The entry module lives at `src/Main.ipe` unless `package.ipe` names another:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

Any module of the program sits under `src/` the same way:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And so does a program that imports from the standard library:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
