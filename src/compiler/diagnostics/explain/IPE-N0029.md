# IPE-N0029: server-only effect in a wasm build

A build with `--target wasm` produces a browser bundle. That bundle is fully
public: every visitor downloads it, and anyone can open it with `wasm2wat` and
read every string inside it. So the compiler enforces a hard boundary — a
kernel that only makes sense on a server (or that could carry a secret into
the bundle) simply *does not exist* for the wasm target. Naming one in code
the entry reaches is this error.

Think of the wasm target as a smaller dictionary: pure functions
(`String.*`, `List.*`, `Json.*`, `Decimal.*`, …) and the whole `Ipe.Ui` /
`Ipe.Html` render surface are all there. Words like `Db.query`,
`File.readFile`, `System.getenv`, `Auth.signToken`, or `Server.listen` are
not in that dictionary at all — not "forbidden", *absent* — so a program that
names them cannot be given a meaning for the browser.

Here a wasm build names a filesystem effect; a browser tab has no filesystem:

```ipe ipe:skip
main =
    File.readFile "notes.txt"
```

And here one names the token signer — the sharpest case, because signing
consumes the server's secret, and a kernel that consumed it client-side would
compile that secret into a public file:

```ipe ipe:skip
sessionToken userId =
    Auth.signToken tokenSecret userId
```

Why so strict? Two reasons:

1. **Secrets.** With no client kernel to consume it, a secret has no path
   into the bundle — the leak is unrepresentable, not merely discouraged.
2. **No implementation exists.** A browser tab has no filesystem, no process
   table, no listening socket. A runtime stub that returns an error at click
   time would hide the mistake until production; a compile error surfaces it
   now.

The fix is architectural, and it is the same one every web app uses: run the
effect on a server, expose it as an HTTP route, and call that route from the
client:

```ipe ipe:skip
-- server (native target): owns the DB
main =
    Server.listen 8000
        [ Server.get "/api/items" (\_ -> loadItems) ]

-- client (wasm target): reaches it over HTTP
update msg model =
    case msg of
        Refresh ->
            ( model, Cmd.perform (Http.get "/api/items") GotItems )
```

Effect kernels that *do* have a browser analogue (HTTP via `fetch`, timers,
`Log.*` to the console, random values from the browser's crypto source) gain
wasm support as their browser substitutes land in the runtime; until a
substitute exists, the kernel stays absent so an accepted program always
builds and runs.

## Glossary

- **kernel** — a standard-library function implemented by the runtime rather
  than by Ipê source.
- **denotation** — the meaning a name resolves to. "No denotation for target
  `wasm`" = for this target, the name names nothing.
- **target** — the platform a build compiles for: `native` (your machine or a
  server) or `wasm` (the browser).
