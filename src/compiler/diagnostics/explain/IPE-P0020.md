# IPE-P0020: malformed module header

Every Ipe file starts with a module header, and the one at the top of
this file isn't in the shape I expect. The header names the module and
lists what it shares with the rest of your program, and I couldn't read
it through to the end.

The shape is fixed: the keyword `module`, then the module name, then
`exposing`, then a parenthesised list of what's public. A missing
piece — no `exposing`, a name that doesn't match the file, or a stray
token between the parts — leaves the header incomplete and lands you
here.

A header with no `exposing` clause is incomplete:

```ipe ipe:error
module Main
```

Add the `exposing` clause that says what the module offers:

```ipe
module Main exposing (main)
```

Expose everything at once with `(..)` when that's what you want:

```ipe ipe:skip illustrates an expose-everything header in isolation, not a runnable program here
module Utils exposing (..)
```

And a fully spelled-out header for a module that shares several names:

```ipe ipe:skip illustrates a header exposing several names in isolation, not a runnable program here
module Math exposing (add, subtract, pi)
```
