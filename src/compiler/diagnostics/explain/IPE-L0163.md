# IPE-L0163: a literal attribute name is reserved for the runtime

The Ipê runtime writes its own markers into the page: the `ipe-*` event and
identity attributes, the style `nonce`, and every `data-ipe-*` name. The one
exception is `ipe-key`, the key of a keyed list. A view cannot set a reserved
name by hand: `Attr.attribute`, `Attr.boolAttribute`, and `Ui.htmlAttribute`
build no attribute from a name computed at run time, so it never reaches the
page. A literal name, written in the call or passed through a partial
application such as `List.map (Attr.attribute "data-ipe-path") paths`, is
refused at compile time instead. Case does not matter: `Data-Ipe-Path` is
the same name.

A routed app needs no attribute to tell the browser its address: the URL
follows `model.page`. When `update` sets a new page, the runtime writes that
page's route to the address bar.

```ipe ipe:error
module Main exposing (main)

import Ipe.Html as Html
import Ipe.Html.Attributes as Attr
import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.html (Html.node "div" [ Attr.attribute "data-ipe-path" "/about" ] [])   -- ✘ the runtime owns `data-ipe-*`.

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage, Web.route "/about" AboutPage ]
        , notFound = HomePage
        }
```

Set the page in `update`; the address bar follows it:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage

type alias Model = { page : Page }

type Msg = ShowAbout

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update msg model =
    case msg of
        ShowAbout ->
            ( { model | page = AboutPage }, Cmd.none )   -- ✔ the URL becomes `/about`.

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.button [] { onPress = Just ShowAbout, label = Ui.text "About" }

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage, Web.route "/about" AboutPage ]
        , notFound = HomePage
        }
```

For your own data on an element, pick a name outside the reserved
namespaces, such as `data-section`.
