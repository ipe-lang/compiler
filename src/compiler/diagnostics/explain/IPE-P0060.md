# IPE-P0060: malformed case expression

I was reading a `case` expression and its shape isn't right. A `case`
chooses among possibilities by writing the value to inspect, the
keyword `of`, and then one or more arms — each a pattern, an arrow
`->`, and the result for that pattern.

Something in that structure is missing here: perhaps the `of` keyword,
the `->` on an arm, the result after an arrow, or the arms aren't lined
up consistently. Each arm must start at the same indentation so I can
tell where one ends and the next begins.

A `case` with no arms after `of` has nothing to choose between:

```ipe ipe:error
describe n =
    case n of
```

Give it arms — a pattern, `->`, and a result for each:

```ipe
describe n =
    case n of
        0 -> "zero"
        _ -> "many"
```

Matching on a custom type follows the same shape, one arm per
constructor:

```ipe
type Color
    = Red
    | Green
    | Blue

toHex color =
    case color of
        Red -> "#ff0000"
        Green -> "#00ff00"
        Blue -> "#0000ff"
```
