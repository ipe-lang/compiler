# IPE-P0014: unterminated string literal

I started reading a string literal at an opening `"` but reached the
end of the line (or the end of the file) before finding the matching
closing `"`. A Ipe single-line string must open and close with a `"`
on the same line, so without that closing quote I cannot tell where
the string ends and the rest of the program begins.

Rather than guess where the string was meant to stop — which could
swallow real code or split it in the wrong place — I stop here and
ask for the missing quote. Add the closing `"`, or escape any literal
quote inside the string with `\"`.

A string with no closing quote lands here:

```ipe ipe:error
greeting =
    "hello
```

Closing the quote fixes it:

```ipe
greeting =
    "hello"
```

A quote that is part of the text must be escaped so it does not end
the string early:

```ipe
quoted =
    "she said \"hi\""
```

A `"""` string with no closing `"""` before the end of the file lands here
too; the error points at the opening `"""` and the end of the file:

```ipe ipe:error
greeting =
    """
    hello
```

Close the block with a `"""` on its own line, in the column of the opening
one:

```ipe
greeting =
    """
    hello
    """
```
