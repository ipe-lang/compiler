# IPE-P0073: a control character a terminal runs as a command

The file holds a raw control character that a terminal runs as a command when
it shows the file: escape (`U+001B`) and control sequence introducer (`U+009B`)
start sequences that move the cursor and erase lines, backspace (`U+0008`)
steps back over the text before it, and the other C0 controls (`U+0000`–`U+0008`,
`U+000E`–`U+001F`), delete (`U+007F`) and the C1 controls (`U+0080`–`U+009F`)
are commands a terminal may act on or swallow. Shown with `cat`, `head` or a
pager that does not escape them, such a character can overwrite or hide the
code around it, so you would read one program and the compiler another. The
compiler refuses it anywhere in a source file: in a comment, among code, and
inside a string or character literal too.

Tab (`U+0009`), newline (`U+000A`) and a carriage return directly before a
newline are the ordinary line structure and stay accepted. Vertical tab, form
feed and next line (`U+000B`, `U+000C`, `U+0085`) are line breaks to a viewer
and are refused as IPE-P0072.

The characters are invisible in most editors, so this page writes escape as
`‹ESC›`. In a terminal, `‹ESC›[1A‹ESC›[2K` moves the cursor up one line and
erases it, so `cat` of the file below shows no `if` line, while the compiler
reads it:

```ipe ipe:skip a raw control character cannot be written safely in a Markdown page
module Gate exposing (allowed)

allowed : Bool -> Bool
allowed authorized =
    if authorized then True else False
    -- reviewed‹ESC›[1A‹ESC›[2K
```

## To fix

Delete the character. Most editors can reveal control characters (a "render
control characters" or "show invisibles" setting) so you can find it; `cat -v`
shows escape as `^[`. The file then shows the code the compiler reads:

```ipe
module Gate exposing (allowed)

allowed : Bool -> Bool
allowed authorized =
    if authorized then True else False
    -- reviewed
```

If a value needs the character, for example to colour terminal output, build
it from its code point with `Char.fromCode` instead of typing it raw:

```ipe
module Colour exposing (red)

import Ipe.Char as Char
import Ipe.String as String

red : String -> String
red text =
    String.fromChar (Char.fromCode 27) ++ "[31m" ++ text ++ String.fromChar (Char.fromCode 27) ++ "[0m"
```
