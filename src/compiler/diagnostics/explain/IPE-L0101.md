# IPE-L0101: operator not supported yet

You used a binary operator that Ipe can parse but cannot compile yet.
Arithmetic, comparison, boolean, and string-append (`++`) operators are
all wired through to the backend. The one holdout is the list-cons
operator `::` used as an expression — it's recognised by the grammar,
but lowering it isn't implemented in this version.

This is a gap in the compiler, not an error in your thinking — `::`
means exactly what you'd expect (prepend an element to a list), it
just doesn't have a code path yet. The span points at the operator
that stopped me.

`[feature: binops]`

`::` as a binary operator isn't available yet:

```ipe ipe:skip the `::` operator form is not yet lowered
withHead : List Int
withHead =
    1 :: [ 2, 3 ]
```

Use `List.cons`, which does the same job and is fully supported:

```ipe
import Ipe.List

withHead : List Int
withHead =
    List.cons 1 [ 2, 3 ]
```

This is a current limitation, not a mistake you made. If you need the
`::` operator form soon, let us know at
https://github.com/ipe-lang/compiler/issues and we'll bump it up the
list.
