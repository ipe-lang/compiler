# IPE-L0158: a route can never match because an earlier route matches first

Routes are tried in order and the first match wins. A route is unreachable
when an earlier route matches every path it matches: either the earlier
pattern is equivalent to it (see IPE-L0157), or, segment by segment, the
earlier route has the same literal, a `String` parameter, which matches any
segment, or a parameter whose type reads the later literal (`7` for an `Int`,
`true` for a `Bool`).

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = AppPage String | NewAppPage

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = NewAppPage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/apps/:slug" AppPage, Web.route "/apps/new" NewAppPage ]   -- ✘ `/apps/:slug` (a `String`) already matches `/apps/new`.
        , notFound = NewAppPage
        }
```

```ipe ipe:skip a before/after diff on one route table; the rest of the app is unchanged from above
-- ✔ List the more specific route first.
routes = [ Web.route "/apps/new" NewAppPage, Web.route "/apps/:slug" AppPage ]
```

The same page listed twice under one pattern is also dead:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = AboutPage

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = AboutPage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/about" AboutPage, Web.route "/about" AboutPage ]   -- ✘ the second `/about` never matches.
        , notFound = AboutPage
        }
```

An `Int` parameter shadows a literal it reads, so `/posts/:id` before
`/posts/7` is refused. It does not shadow a literal like `latest`, which does
not parse as an `Int`:

```ipe ipe:skip a fragment; PostPage and LatestPage are assumed from context
-- ✔ `/posts/latest` is still reachable.
routes = [ route "/posts/:id" PostPage, route "/posts/latest" LatestPage ]
```
