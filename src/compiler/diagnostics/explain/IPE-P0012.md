# IPE-P0012: number joined to a name

I read a number that runs straight into a letter with no space between
them, like `3x` or `42abc`. Ipe won't treat that as one token, because
a name can't begin with a digit and a number can't have letters glued
to its end — so I can't tell which one you meant.

If you wanted to multiply, put the operator (and a space) between them.
If you meant a single identifier, remember that names must start with a
letter. Either way, the fix is to separate the digits from the letters.

A number pressed against a name is read as this error, not as
multiplication:

```ipe ipe:error
area =
    2width
```

Write the multiplication out so each part stands alone:

```ipe
width = 3

area =
    2 * width
```

If you meant a name, start it with a letter rather than a digit:

```ipe
v2 =
    10
```
