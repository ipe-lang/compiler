# IPE-E0012: a build command given a file

`ipe dev build`, `ipe dev run`, `ipe dev watch`, `ipe release build`,
`ipe release run` and `ipe release eject` build a whole project. They take the
project directory, the one holding `package.ipe`, or nothing for the current
directory. They never take a `.ipe` file.

The project's manifest names its programs, so the build reads the entry from
`package.ipe`, never from a file argument. A file argument would let the
command line pick an entry the manifest does not declare.

What to try:

1. **Pass the project directory instead of the file**. The message names it
   when the file is the project's `package.ipe`.
2. Run the command with no argument from inside the project.
3. To check one module, run `ipe type-check <file>` or `ipe dev lint <file>`.
   Those commands take a file.

The default entry is `src/Main.ipe`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

An entry may define values beside `main`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And it may import from the standard library:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
