# IPE-E0013: host toolchain missing

The compiler translated your Ipe program to Rust, and the build then stopped
because the host is missing a toolchain component the build needs — not
because of a mistake in your code, and not a bug in the compiler.

The message names which component is missing and how to install it. Two
common cases:

- **A target's Rust standard library is not installed** — for example,
  building for `aarch64-unknown-linux-musl` without that target added to your
  active `rustup` toolchain. The remedy is always `rustup target add
  <triple>` (or `rustup target add --toolchain <label> <triple>` when you are
  not on the default toolchain).
- **No C compiler can target a musl cross build** — a host C compiler was
  found, but it cannot produce code for the requested musl triple. The remedy
  is to install a musl cross compiler for your distribution (for example,
  Debian/Ubuntu's `musl-tools`, Fedora's `musl-gcc`, Arch's `musl`, or
  Alpine's `build-base`), or to point the build at one directly by setting
  the `CC_<triple>` environment variable (with underscores in place of the
  triple's dashes) to its path.

What to try:

1. **Add the missing target**: `rustup target add <triple>`.
2. **Install a musl C compiler** for your distribution's package, or point
   `CC_<triple>` at a musl cross compiler you already have installed.
3. Re-run the build; the diagnostic disappears once the host has everything
   the target needs.

Your Ipe program has nothing to fix — here is a valid program that builds
once the host toolchain is complete:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A type-annotated variant also compiles fine:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

There is nothing to change in your source — just complete the host toolchain
and try again:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
