# IPE-T0012: this record has no such field

A `record.field` access named a `field` that the record's type does not
contain — or the value before the `.` is not a record at all.

Ipe records are **closed**: a record's type lists an exact, known set of
fields. Reading a field that is not in that set cannot succeed, so the
compiler rejects it rather than producing a value that does not exist.

## A field that is not there

This record has `x` and `y`, but no `z`:

```ipe ipe:error
import Ipe.Io as Io
import Ipe.String as String

main : Task Error ()
main =
    let
        point = { x = 1, y = 2 }
    in
    Io.println (String.fromInt point.z)
```

The fix is to read a field that exists:

```ipe
import Ipe.Io as Io
import Ipe.String as String

main : Task Error ()
main =
    let
        point = { x = 1, y = 2 }
    in
    Io.println (String.fromInt point.x)
```

## The base is not a record

A `.field` access only makes sense on a record. Here `count` is an `Int`,
so `count.x` has nothing to read:

```ipe ipe:error
import Ipe.Io as Io
import Ipe.String as String

main : Task Error ()
main =
    let
        count = 41
    in
    Io.println (String.fromInt count.x)
```

Give the binding a record value if you meant to read a field from it, or
drop the `.field` if you meant to use the value directly.
