# IPE-F4415: a crate being added needs a system library that is not installed

The crate you are adding links against a native system library (a
`.so` / `.dylib` / `.dll` or its `pkg-config` `.pc` descriptor) that
`pkg-config` cannot find on your machine. The build stopped rather
than emit a program that cannot link.

A successful add ends with an ordinary import:

```ipe ipe:skip illustrates calling a Rust crate binding, not a runnable program here
import Rust.Wayland as Wayland

main = Wayland.connect |> Task.andThen Wayland.render
```

The message names the missing library and the crate that declared the
dependency, so you know exactly what to install.

## What to do

Install the development package that ships the library. The examples
below are illustrative — the exact package name depends on your
distribution and the library in question:

```ipe ipe:skip illustrates the shell commands to install the missing library, not Ipe source
-- Debian / Ubuntu:  apt install lib<name>-dev
-- Fedora / RHEL:    dnf install <name>-devel
-- macOS (Homebrew): brew install <name>
-- Arch Linux:       pacman -S <name>
```

For `wayland-client` specifically: `libwayland-dev` (Debian / Ubuntu),
`wayland-devel` (Fedora), or `wayland` (Homebrew / Arch).

If the library is installed in a non-standard path, point `pkg-config`
to its `.pc` file before re-running:

```ipe ipe:skip illustrates setting an environment variable, not Ipe source
-- PKG_CONFIG_PATH=/usr/local/lib/pkgconfig ipe rust add <crate>
```

Run `ipe rust add <crate>` again once the library is installed.

## Why this is a hard error

`ipe` compiles the crate's Rust source inside a sandboxed jail.  When a
`build.rs` or a `sys`-crate calls `pkg-config` and the library is
missing, the jail's cargo exits non-zero — there is no path to a
working binary. Reporting the root cause here avoids a firehose of raw
cargo output whose signal is buried at the end.

## Glossary

- **`pkg-config`** — a tool that tells the compiler where a system
  library's headers and link flags live. Many `-sys` Rust crates use it
  to find the native library they wrap.
- **`-dev` / `-devel` package** — the distribution package that adds the
  C headers and `.pc` descriptor a library needs at compile time (the
  plain package often ships only the runtime `.so`).
- **`PKG_CONFIG_PATH`** — an environment variable that extends the list of
  directories `pkg-config` searches for `.pc` files.
