# IPE-N0003: cannot find this constructor

You matched on a constructor in a `case` pattern that is not defined anywhere in scope. Constructors are the tags you list when you declare a `type`, like `Red`, `Just`, or `Ok`. I could not find one with the name you wrote.

This is most often a typo, or a constructor from a type you have not declared (or not imported) yet. If your name is close to a constructor I do know, I will suggest it. Remember that constructor names always start with an uppercase letter — a lowercase name in a pattern binds a variable, not a constructor. An unknown name in an expression, rather than a pattern, is IPE-N0001.

Here a constructor is misspelled in a pattern:

```ipe ipe:error
type Color
    = Red
    | Green
    | Blue

name : Color -> String
name color =
    case color of
        Red ->
            "red"

        Gren ->
            "green"

        Blue ->
            "blue"
```

I do not have a constructor `Gren`. You meant `Green` — every pattern tag must be a constructor that exists on the type you are matching:

```ipe
type Color
    = Red
    | Green
    | Blue

name : Color -> String
name color =
    case color of
        Red ->
            "red"

        Green ->
            "green"

        Blue ->
            "blue"
```

A constructor of an imported type is in scope bare only when the import opens it, with `T(..)` or `T(C)`, or qualified as `M.C`. Naming one the module does not expose is refused at the import (IPE-N0022).
