# IPE-L0159: a page constructor has no route

In a routed app (its Model has a `page` field), every constructor of the
page type needs at least one route. The compiler renders the page held in
`model.page` back into its canonical path (the first route listed for that
constructor), so a page with no route would have no address. This includes
the `notFound` page.

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage | NotFoundPage

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage ]   -- ✘ `AboutPage` and `NotFoundPage` have no route.
        , notFound = NotFoundPage
        }
```

Give each page a path. A page may have several routes; the first one listed
is canonical and the others redirect to it:

```ipe ipe:skip a fragment; HomePage, AboutPage, and NotFoundPage are assumed from context
-- ✔ `/home` redirects to `/`.
routes =
    [ route "/" HomePage
    , route "/home" HomePage
    , route "/about" AboutPage
    , route "/not-found" NotFoundPage
    ]
```

An empty `routes` list leaves every page without a route:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage | NotFoundPage

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = []   -- ✘ no page has a route.
        , notFound = NotFoundPage
        }
```
