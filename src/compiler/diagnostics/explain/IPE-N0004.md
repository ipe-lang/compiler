# IPE-N0004: unknown module or import

You wrote a qualified name like `Qual.something`, but the part before the dot — the qualifier — names no module or import alias in scope here, and no module you could import. I checked your imports, the standard library, and your project's modules, and `Qual` matched none of them.

This usually means the qualifier is misspelled, or you are using an alias no import introduces. If the qualifier is close to one this file can use, I will suggest it. A known module you forgot to import is a different error, IPE-N0034, which names the import to add.

Here an imported module's qualifier is misspelled:

```ipe ipe:error
import Ipe.String

shout : String -> String
shout text =
    Strng.toUpper text
```

There is no module `Strng`. You meant `String`:

```ipe
import Ipe.String

shout : String -> String
shout text =
    String.toUpper text
```

If you are using an alias, make sure the import that introduces it is present. Bring the module in, then qualify with the alias you chose. A module imported under an alias answers only to that alias: after `import Lib.Util as U`, writing `Util.f` is IPE-N0034, which names `U` as the qualifier to write. For example:

```ipe
import Ipe.String as Str

shout : String -> String
shout text =
    Str.toUpper text
```

The same holds inside an interpolated string: `"""{{Strng.toUpper name}}"""` is this error too, never the literal text `{{Strng.toUpper name}}`.
