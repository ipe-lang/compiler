# IPE-N0022: name not exposed

You are importing a name from a module that exists, but that module does not expose the name you asked for. This happens when the `exposing (...)` list in your `import` statement asks for a value, type, or constructor that the target module either does not define or has marked private.

The same holds for a qualified type: with `import Lib.Utils as U`, the annotation `U.Helper` is refused when `Lib.Utils` declares `Helper` but leaves it out of its `exposing` list. Expose the type, or use one the module exposes. A type the module does not declare at all is IPE-N0005 instead.

Importing a name that the module does not expose:

```ipe ipe:skip
module Main exposing (main)
import Lib.Utils exposing (add, hiddenHelper)

main = println (String.fromInt (add 1 2))
```

If `Lib.Utils` does not expose `hiddenHelper`, this is an error. Remove `hiddenHelper` from the `exposing` list, or add it to `Lib.Utils exposing (..)`.

Importing constructors that are private:

```ipe ipe:skip
module Main exposing (main)
import Shape exposing (Shape(Circle))
```

```ipe ipe:error
-- src/Shape.ipe
module Shape exposing (Shape)
type Shape = Circle Float | Rectangle Float Float
```

`Shape` exposes the type `Shape` but not its constructors. Either change the export to `Shape(Circle, Rectangle)` or use `Shape(..)` to expose all constructors.

Correct form where everything lines up:

```ipe ipe:error
-- src/Shape.ipe
module Shape exposing (Shape(..))
type Shape = Circle Float | Rectangle Float Float
```

```ipe ipe:skip
module Main exposing (main)
import Shape exposing (Shape(..))
area : Shape -> Float
area s = case s of
    Circle r     -> Math.pi * r * r
    Rectangle w h -> w * h
main = println (String.fromFloat (area (Circle 3.0)))
```
