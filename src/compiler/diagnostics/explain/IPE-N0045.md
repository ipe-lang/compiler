# IPE-N0045: main selects its shape at runtime, but a shape is a compile-time choice

Every Ipê program declares what it *is* through its `main`. A `main = Web.tea …` is a web app; a `main = Tui.tea …` is a full-screen terminal app; a plain `main : Task Error ()` is a script. This kind — the program's *shape* — is fixed when the code is compiled, read straight off the head of `main`. It is not a value the program picks while it runs.

So `main` cannot branch to an app entry. This is refused — even though both branches build the *same* shape, `Web`:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui


debugMode : Bool
debugMode =
    True


type Page
    = HomePage


type Msg
    = NoOp


type alias Model =
    { page : Page }


init : WebReq -> ( Model, Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )


debugView : Model -> Element Msg
debugView _model =
    Ui.text "debug build"


prodView : Model -> Element Msg
prodView _model =
    Ui.text "hello"


subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none


main =
    if debugMode then
        Web.tea
            { init = init
            , update = update
            , view = debugView
            , subscriptions = subscriptions
            , routes = [ Web.route "/" HomePage ]
            , notFound = HomePage
            }
    else
        Web.tea
            { init = init
            , update = update
            , view = prodView
            , subscriptions = subscriptions
            , routes = [ Web.route "/" HomePage ]
            , notFound = HomePage
            }
```

At the moment the head of `main` is an `if` (or a `case`) with an app entry reached from a branch, "which kind of program is this?" would only be answerable at run time — and the whole toolchain (which runtime to link, which entry point to emit, which effects are even in scope) needs the answer before the program runs. One branch reaching an app entry is already enough to make the shape a value, so the compiler turns it back rather than guessing — it does not matter that `debugView` is the only thing that actually differs between the two branches above. (Branching between two *different* shapes, say `Web` and `Tui`, is refused even earlier, at the second shape's import — [IPE-N0035](IPE-N0035.md).)

The fix is to commit `main` to one shape, and move the run-time choice *inside* that shape:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Ui as Ui
import Ipe.Tea.Web.Cmd
import Ipe.String
import Ipe.Tea.Web.Sub


type Page
    = HomePage


type Msg
    = NoOp


type alias Model =
    { page : Page }


init : WebReq -> ( Model, Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )


view : Model -> Element Msg
view _model =
    Ui.text "hello"


subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none


main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage ]
        , notFound = HomePage
        }
```

Anything you wanted to decide at run time still can be — but it belongs in that shape's own logic (its `init`, `update`, or the `Task` a script runs), where the program is already running and a value is exactly the right way to choose. What cannot vary is the shape itself.

If the program is a plain script, make `main` a `Task Error ()`: a task is free to branch on any value it likes, because a script is one shape no matter what the task computes.

```ipe
module Main exposing (main)

import Ipe.Task as Task


shouldGreet : Bool
shouldGreet =
    True


main : Task Error ()
main =
    if shouldGreet then
        Task.succeed ()
    else
        Task.succeed ()
```

The rule in one line: one `main`, one shape, chosen when you write it — never when it runs.
