# IPE-N0045: main selects its shape at runtime, but a shape is a compile-time choice

Every Ipê program declares what it *is* through its `main`. A `main = Web.tea …` is a web app; a `main = Tui.tea …` is a full-screen terminal app; a plain `main : Task Error ()` is a script. This kind — the program's *shape* — is fixed when the code is compiled, read straight off the head of `main`. It is not a value the program picks while it runs.

So `main` cannot branch between shapes. This is refused:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as WebCmd
import Ipe.Tea.Web.Sub as WebSub
import Ipe.Ui as Ui
import Ipe.Tea.Tui as Tui
import Ipe.Tea.Tui.Cmd as TuiCmd
import Ipe.Tea.Tui.Sub as TuiSub
import Ipe.Ui.Tui as TuiUi


runningInBrowser : Bool
runningInBrowser =
    True


type WebPage
    = HomePage


type WebMsg
    = WebNoOp


type alias WebModel =
    { page : WebPage }


webInit : WebReq -> ( WebModel, Cmd WebMsg )
webInit _req =
    ( { page = HomePage }, WebCmd.none )


webUpdate : WebMsg -> WebModel -> ( WebModel, Cmd WebMsg )
webUpdate _msg model =
    ( model, WebCmd.none )


webView : WebModel -> Element WebMsg
webView _model =
    Ui.text "web"


webSubscriptions : WebModel -> Sub WebMsg
webSubscriptions _model =
    WebSub.none


webConfig =
    { init = webInit
    , update = webUpdate
    , view = webView
    , subscriptions = webSubscriptions
    , routes = [ Web.route "/" HomePage ]
    , notFound = HomePage
    }


type alias TuiModel =
    { count : Int }


type TuiMsg
    = TuiNoOp


tuiInit : () -> ( TuiModel, Cmd TuiMsg )
tuiInit _unit =
    ( { count = 0 }, TuiCmd.none )


tuiUpdate : TuiMsg -> TuiModel -> ( TuiModel, Cmd TuiMsg )
tuiUpdate _msg model =
    ( model, TuiCmd.none )


tuiView : TuiModel -> Screen TuiMsg
tuiView _model =
    TuiUi.text "tui"


tuiSubscriptions : TuiModel -> Sub TuiMsg
tuiSubscriptions _model =
    TuiSub.none


tuiConfig =
    { init = tuiInit
    , update = tuiUpdate
    , view = tuiView
    , subscriptions = tuiSubscriptions
    }


main =
    if runningInBrowser then
        Web.tea webConfig
    else
        Tui.tea tuiConfig
```

At the moment the head of `main` is an `if` (or a `case`) whose branches are different app entries, "which kind of program is this?" would only be answerable at run time — and the whole toolchain (which runtime to link, which entry point to emit, which effects are even in scope) needs the answer before the program runs. A shape decided from a value has no single answer, so the compiler turns it back rather than guessing.

The fix is to commit `main` to one shape, and move the run-time choice *inside* that shape:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Ui as Ui
import Ipe.Tea.Web.Cmd
import Ipe.String
import Ipe.Tea.Web.Sub


type Page
    = HomePage


type Msg
    = NoOp


type alias Model =
    { page : Page }


init : WebReq -> ( Model, Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )


view : Model -> Element Msg
view _model =
    Ui.text "hello"


subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none


webConfig =
    { init = init
    , update = update
    , view = view
    , subscriptions = subscriptions
    , routes = [ Web.route "/" HomePage ]
    , notFound = HomePage
    }


main =
    Web.tea webConfig
```

Anything you wanted to decide at run time still can be — but it belongs in that shape's own logic (its `init`, `update`, or the `Task` a script runs), where the program is already running and a value is exactly the right way to choose. What cannot vary is the shape itself.

If the program is a plain script, make `main` a `Task Error ()`: a task is free to branch on any value it likes, because a script is one shape no matter what the task computes.

```ipe
module Main exposing (main)

import Ipe.Task as Task


shouldGreet : Bool
shouldGreet =
    True


main : Task Error ()
main =
    if shouldGreet then
        Task.succeed ()
    else
        Task.succeed ()
```

The rule in one line: one `main`, one shape, chosen when you write it — never when it runs.
