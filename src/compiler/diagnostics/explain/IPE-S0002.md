# IPE-S0002: a web capability is reached without the app's grant

Your program reaches a browser capability — the clipboard, the microphone,
geolocation, and the like — through a reserved `Ipe.Browser.<Api>` module, and
the app's `package.ipe` has not granted it. Reaching such a module *discloses*
a `js-port:<axis>` capability. Disclosure is not consent: only the top-level
application grants a web axis, so I stop the build before it ships a page that
asks the visitor's browser for something the author never approved.

The refusal names the module that discloses each axis, so a dependency cannot
hide one. A dependency's own grant never composes down the tree: it can
disclose an axis, but it cannot authorise itself.

## The safe path is untouched

Code that imports no `Ipe.Browser.<Api>` module discloses no web axis and needs
no grant:

```ipe
import Ipe.Html exposing (text, section)

view summary =
    section [] [ text summary ]  -- no browser capability: nothing to grant
```

## What triggers the refusal

Importing a reserved browser module is the trigger, whether your own code or a
dependency does it:

```ipe ipe:skip needs a Web app and a package.ipe, which a single fence cannot carry
import Ipe.Browser.Clipboard as Clipboard

-- reaching the clipboard discloses `js-port:clipboard`
```

## How to grant it

Review what the module does, then add the axis to the `accepts` set under
`capabilities` in the app's `package.ipe`. Drop the dependency instead when you
do not want the capability at all:

```ipe ipe:skip a manifest fragment, shown for its shape
-- package.ipe
-- package =
--     { name = "my-app"
--     , capabilities = { accepts = [ JsPort Clipboard ] }
--     }
```

## A capability that cannot be attributed

When the program carries a web axis but no scanned module can be named as its
source, I refuse as well and say so. An axis I cannot attribute is never
dropped, because a grant I cannot trace to a reviewed import is not a grant.

## Glossary

- **web axis** — one browser capability, such as `clipboard` or `microphone`,
  written `js-port:<axis>` on the wire and `JsPort <Axis>` in the manifest.
- **disclose** — to make a capability visible to the build. A disclosed axis
  is judged against the grant; it is not yet permitted.
- **fail closed** — when consent is absent or cannot be traced, refuse rather
  than proceed.
