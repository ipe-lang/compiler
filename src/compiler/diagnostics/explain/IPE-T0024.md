# IPE-T0024: this type grows every time it refers to itself

A custom type may refer to itself: a list holds the rest of the list, a tree
holds its subtrees. This error means a custom type refers to itself with one of
its parameters wrapped inside a larger type, so each level of a value is a
bigger type than the level above it:

```ipe ipe:error
type Nested a
    = Leaf a
    | Nest (Nested (List a))
```

A `Nested Int` holds a `Nested (List Int)`, which holds a
`Nested (List (List Int))`, and so on without end. The message names the type
and the parameter that grows.

## Why it is refused

Every type turns into a Rust type when your program is compiled, and the Rust
compiler builds each of these growing types one after another. A type whose
levels keep growing never runs out of new types to build, so the Rust build
stops with an overflow error. Refusing the declaration here, where the type is
written, is better than that failure.

## Right

Refer to the type with its parameters exactly as they are, and hold the
growing part in a field of its own:

```ipe
type Nested a
    = Leaf a
    | Nest (List (Nested a))
```

Here every level is a `Nested a`, so the type stays the same however deep the
value goes.
