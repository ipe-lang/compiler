# IPE-E0010: a symbolic link inside the project

A file or directory ipe reads from the project — `package.ipe`, a module under
`src/`, or the `tests/` directory — is a symbolic link.

ipe never follows a link inside a project. A link can point out of the
project, into another user's files, or somewhere that changes between two
builds, so the code ipe compiled would not be the code the project holds.

What to try:

1. **Replace the link with the real file or directory.**
2. If the linked code is shared between projects, depend on it as a package
   instead.

Modules are plain files under `src/`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A module may define values beside `main`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And it may import from the standard library:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
