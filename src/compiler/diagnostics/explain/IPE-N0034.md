# IPE-N0034: module used without importing it

You wrote a qualified name like `String.join`, and `String` really is a module I know — one of my standard-library modules or a module of your project — but this file never imports it. I do not make modules ambiently available. Each file's `import` list is a complete inventory of what it reaches for, so a module you use qualified must first be imported.

Only a small, fixed vocabulary is available with no import: the operators and base types (`+`, `==`, `identity`, `Int`, `String`, …) and the core-language types `Maybe`, `Result`, `List` with their constructors. Everything else — `String`, `List`, `Dict`, `Http`, `Json.Decode`, your own modules, and the rest — is used qualified and must be imported.

Here `String` is used with no import, so it does not resolve:

```ipe ipe:error
shout : String -> String
shout text =
    String.toUpper text
```

Add the import the message names (`import Ipe.String`), and the qualified use resolves:

```ipe
import Ipe.String

shout : String -> String
shout text =
    String.toUpper text
```

The same rule holds for every module, your own included. Import each one you qualify against:

```ipe ipe:skip
import Ipe.Dict
import Ipe.List

tally : List String -> Dict String Int
tally words =
    List.foldl (\word acc -> Dict.update word bump acc) Dict.empty words
```

When several modules answer to the same qualifier — `App.Util` and `Lib.Util` both bind `Util` — the message lists each one; import the one you meant. An editor offers each as its own "Add import" fix.

If instead the qualifier is genuinely unknown — a misspelling, or a module that does not exist — you will see IPE-N0004 rather than this error.

## An alias answers only to itself

`import Ipe.String as Str` makes the module reachable as `Str` and nothing else. Its own name `String`, and a dotted spelling such as `Ipe.String`, stay unimported, so using them is this error; the message names the alias you chose:

```ipe ipe:error
import Ipe.String as Str

shout : String -> String
shout text =
    String.toUpper text
```

Write the alias instead:

```ipe
import Ipe.String as Str

shout : String -> String
shout text =
    Str.toUpper text
```

## `Cmd` and `Sub` come from a shape

`Cmd` and `Sub` are reachable only once the file imports an app shape (`Ipe.Tea.Web`, `Ipe.Tea.Tui`, `Ipe.Tea.Cli`, `Ipe.Tea.Worker`) or that shape's own `Cmd` / `Sub` module. With no such import, `Cmd.none` is this error, listing the shape modules:

```ipe ipe:error
idle =
    Cmd.none
```

## Interpolated names follow the same rule

A qualified name inside `{{ }}` resolves exactly as it does outside a string, so a module it names must be imported:

```ipe ipe:error
greet : String -> String
greet name =
    """Hello, {{String.toUpper name}}!"""
```

## `|=` and `|.` come from `Ipe.Parser`

The parser operators `|=` and `|.` are calls into `Ipe.Parser` (`ignore` and `keep`), so they too need the module imported. Any import form counts — `import Ipe.Parser`, `import Ipe.Parser as P`, or `import Ipe.Parser exposing (..)`. With no such import, the operator is this error:

```ipe ipe:error
skipComma comma value =
    comma |= value
```

Import the module, and the operator resolves:

```ipe
import Ipe.Parser as Parser exposing (Parser)

commaThenInt : Parser Int
commaThenInt =
    Parser.symbol "," |= Parser.int
```
