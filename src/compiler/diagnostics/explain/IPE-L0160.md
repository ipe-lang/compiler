# IPE-L0160: a routed app's routes are not a literal list of `Web.route` calls

The compiler reads a routed app's `routes` at compile time to derive the
page parser and its inverse, the renderer. It can read a list written inline
in the app record, or a top-level value whose body is such a list. Each entry
is `Web.route "<literal path>" PageConstructor`.

A computed table cannot be read:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui
import Ipe.List as List

type Page = HomePage | AdminPage

type alias Model = { page : Page }

type Msg = NoOp

baseRoutes = [ Web.route "/" HomePage ]
adminRoutes = [ Web.route "/admin" AdminPage ]

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = List.append baseRoutes adminRoutes   -- ✘ the table is built by a function call.
        , notFound = HomePage
        }
```

A pattern must be a string literal:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = SectionPage String

type alias Model = { page : Page }

type Msg = NoOp

section : String
section = "docs"

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = SectionPage section }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route ("/" ++ section) SectionPage ]   -- ✘ the pattern is computed.
        , notFound = SectionPage "missing"
        }
```

Write the table out:

```ipe ipe:skip a fragment; HomePage and AdminPage are assumed from context
-- ✔ A top-level literal table.
appRoutes =
    [ Web.route "/" HomePage
    , Web.route "/admin" AdminPage
    ]
```
