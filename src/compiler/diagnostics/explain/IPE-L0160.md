# IPE-L0160: a routed app's routes are not a literal list of `Web.route` calls

The compiler reads a routed app's `routes` at compile time to derive the
page parser and its inverse, the renderer. It can read a list written inline
in the app record, or a top-level value whose body is such a list. Each entry
is `Web.route "<literal path>" PageConstructor`.

A computed table cannot be read:

```ipe ipe:error
-- ✘ The table is built by a function call.
routes = List.append baseRoutes adminRoutes
```

A pattern must be a string literal:

```ipe ipe:error
-- ✘ The pattern is computed.
routes = [ route ("/" ++ section) SectionPage ]
```

Write the table out:

```ipe ipe:skip a fragment; `HomePage` and `AdminPage` are assumed from context
-- ✔ A top-level literal table.
appRoutes =
    [ Web.route "/" HomePage
    , Web.route "/admin" AdminPage
    ]
```
