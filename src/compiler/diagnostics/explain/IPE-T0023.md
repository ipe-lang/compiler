# IPE-T0023: this type is too large

A type is built from parts: a pair `( a, b )` is one part plus the parts of
`a` and `b`. This error means the type of a value is built from more parts than
I allow — 65,536 — once every repeated piece is counted where it appears.

The usual source is a value that holds the one before it twice. Each step
doubles the size of the type, so a short chain is already enormous:

```ipe ipe:error
module Main exposing (main)

import Ipe.Io as Io


main =
    let
        p0 = 0
        p1 = ( p0, p0 )
        p2 = ( p1, p1 )
        p3 = ( p2, p2 )
        p4 = ( p3, p3 )
        p5 = ( p4, p4 )
        p6 = ( p5, p5 )
        p7 = ( p6, p6 )
        p8 = ( p7, p7 )
        p9 = ( p8, p8 )
        p10 = ( p9, p9 )
        p11 = ( p10, p10 )
        p12 = ( p11, p11 )
        p13 = ( p12, p12 )
        p14 = ( p13, p13 )
        p15 = ( p14, p14 )
        p16 = ( p15, p15 )
    in
    Io.println (if p16 == p16 then "same" else "differs")
```

`p16` is only sixteen definitions long, but its type has 2^17 − 1 parts. The
message names the limit and never prints the type, because printing it would
write out every one of those parts.

## A custom type whose uses widen

A custom type can reach the same size without any value: a type that refers
to itself with larger arguments builds a larger type at each level, even
though every level stays shallow. The error then points at the constructor
that applies the larger arguments, whether the type is used or not:

```ipe ipe:skip an outline of a widening type; the real `B` takes 40 parameters
type B p1 p2 p3 = B p1 p2 p3

type T a b c d
    = Z
    | X (T Int (B a a a) (B b b b) (B c c c))
```

Each level of `T` holds `B` over the arguments of the level before, so its
last argument is `B` of `B` of `B`, each over every parameter of `B`. Pass
the parameters on as they are, or hold the growing part in a field of its own
type, such as a `List`.

## Why the limit exists

The checker, the code generator and the Rust compiler each walk the whole
type, part by part. Without a ceiling, a few lines of source could make them
use memory and time without end. Stopping with a clear error at the place that
crossed the line keeps the compiler fast and its memory bounded.

## Right

Name the repeated part with its own type, so the type stays small however the
value grows:

```ipe
type Tree
    = Leaf Int
    | Node Tree Tree

tree : Tree
tree =
    Node (Leaf 0) (Leaf 1)
```

When the data really is a long sequence, keep it in a list:

```ipe
pairs : List ( Int, Int )
pairs =
    [ ( 0, 0 ), ( 1, 1 ) ]
```
