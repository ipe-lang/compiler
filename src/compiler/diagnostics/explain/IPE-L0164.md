# IPE-L0164: a function needs to copy a value that cannot be copied

Some functions do more with a value than hand it along. `List.repeat 3 x`
copies `x` three times; `List.member x xs` compares `x` with every element.
A generic function you write, such as `ident : a -> a`, copies its argument
whenever the body uses it more than once, so the compiler builds every generic
function so that it may.

A few kinds of value cannot be copied: a `Task`, a `Cmd`, a `Sub`, a function
held as a one-shot callback, an app handle, and a foreign handle. Each one is a
description of work that runs once. Handing one to a function that copies,
compares, or shares its argument is refused here, at the call, naming the
function and the part of the value that cannot be copied.

```ipe ipe:error
module Main exposing (main)

import Ipe.Io as Io
import Ipe.List as List
import Ipe.Task as Task

main : Task Error ()
main =
    List.repeat 3 (Io.println "hi")   -- ✘ `List.repeat` copies its element; a `Task` cannot be copied.
        |> Task.sequence
        |> Task.map (\_ -> ())
```

Build each task where it is needed instead. A function that makes a fresh task
for every element needs no copy:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.List as List
import Ipe.Task as Task

main : Task Error ()
main =
    List.map (\_ -> Io.println "hi") (List.range 1 3)
        |> Task.sequence
        |> Task.map (\_ -> ())
```

The same holds for a generic function of your own. `ident` below is built to
copy its argument, so a task cannot be passed to it:

```ipe ipe:error
module Main exposing (main)

import Ipe.Io as Io

ident : a -> a
ident x =
    x

main : Task Error ()
main =
    ident (Io.println "hi")   -- ✘ `ident` copies its argument; a `Task` cannot be copied.
```

Give the task a concrete type in the function's signature, or pass a function
that builds the task:

```ipe
module Main exposing (main)

import Ipe.Io as Io

run : Task Error () -> Task Error ()
run task =
    task

main : Task Error ()
main =
    run (Io.println "hi")
```
