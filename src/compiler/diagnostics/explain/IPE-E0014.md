# IPE-E0014: unsupported host Rust toolchain

The compiler translated your Ipe program to Rust, and refused to build it
because the Rust toolchain the build would use is one the emitted crates do
not support — not because of a mistake in your code, and not a bug in the
compiler.

The emitted crates need the Rust release Ipe is pinned to, or a newer one.
The message names the release it found, the release it needs, and where the
build picks its compiler from. It appears when:

- **The toolchain is older than the pin.** With `rustup`, run `rustup update
  stable`, or install the named release with `rustup toolchain install
  <release>` and select it for the build with `RUSTUP_TOOLCHAIN=<release>`.
  `rustup` picks a toolchain per directory (a `rust-toolchain.toml` file or a
  `rustup override` above the build directory wins over your default), so the
  build may use another toolchain than `rustc --version` reports in your
  shell; the message shows the one the build uses.
- **The build is pointed at another compiler.** The `RUSTC` or
  `CARGO_BUILD_RUSTC` environment variables, or `build.rustc` in a Cargo
  configuration file (`.cargo/config.toml` above the build directory or in
  `CARGO_HOME`), choose the compiler before `PATH` does. Point the one the
  message names at a recent enough compiler, or remove it.
- **The compiler's release cannot be read**, or its configuration cannot be
  read. The build does not guess: it refuses until the compiler answers
  `rustc -vV` with a release it can compare.

What to try:

1. **Update or select the toolchain the message names**, with the command it
   shows.
2. Re-run the build; the diagnostic disappears once the build's compiler is
   the pinned release or newer.

Your Ipe program has nothing to fix — here is a valid program that builds
once the toolchain is recent enough:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A type-annotated variant also compiles fine:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

There is nothing to change in your source — just update the toolchain and try
again:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
