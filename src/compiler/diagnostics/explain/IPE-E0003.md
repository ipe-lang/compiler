# IPE-E0003: the host linker could not open an input file

The compiler translated your Ipe program to Rust, and `cargo` built it, but
the host linker then reported that it could not open one of the files it was
asked to link. This is a problem with where the build lives on your machine —
not a mistake in your code, and not a bug in the compiler.

The message names the file the linker could not open and whether its path
holds non-ASCII characters.

The usual cause is the GNU linker of a `x86_64-pc-windows-gnu` toolchain. It
opens files through the Windows code page, so a path holding a non-ASCII
character (an accent, a non-Latin script) cannot be opened. The path may be
inside the build directory, the Rust toolchain, or the C toolchain the linker
belongs to. The MSVC linker and the `gnullvm` linker open any path.

What to try:

1. **Move the project to an ASCII path**, or set `CARGO_TARGET_DIR` to an
   ASCII directory you own, under your user profile — for example
   `%USERPROFILE%\ipe-target`. Never use a folder at the root of a drive such
   as `C:\ipe-target`: other accounts on the machine can write there and plant
   files the next build links and runs.
2. **Install the `x86_64-pc-windows-msvc` or `x86_64-pc-windows-gnullvm` host
   toolchain** with `rustup`; their linkers open any path.
3. When the file is inside the C toolchain, reinstall it under an ASCII path.

Your Ipe program has nothing to fix — here is a valid program that builds
once the linker can open every input:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A type-annotated variant also compiles fine:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

There is nothing to change in your source — just move the build and try
again:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
