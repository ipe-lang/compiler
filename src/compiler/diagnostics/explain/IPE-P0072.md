# IPE-P0072: a character that breaks or reorders the displayed source

The file holds an invisible character that editors, terminals and code review
tools draw as structure the compiler does not read: a line break (vertical tab
`U+000B`, form feed `U+000C`, next line `U+0085`, line separator `U+2028`,
paragraph separator `U+2029`) or a bidirectional control that reorders the text
around it (`U+202A`–`U+202E`, `U+2066`–`U+2069`). The compiler breaks lines only
at `\n` and reads text in the order it is stored, so the same file would show
you one program and compile another: code you see on its own line could be the
tail of the comment above it, and a string could look closed where it is not.
Rather than pick one reading, the compiler refuses the character.

Where each one may stand:

- Vertical tab, form feed, next line, and the embeddings, pops and overrides
  (`U+202A`–`U+202E`) are refused anywhere in a source file.
- A line or paragraph separator may stand only inside a string or character
  literal, where the compiler reads it as text.
- An isolate (`U+2066`, `U+2067`, `U+2068`, closed by `U+2069`) may stand only
  inside a string or character literal that closes it again, before the literal
  ends and before a line or paragraph ends inside it. A viewer then reorders
  only the text between the pair.

The characters are invisible in most editors, so this page writes a right-to-left
override as `‹RLO›` and a line separator as `‹LS›`. A viewer that honours the
override shows the comment below with its words reversed; a viewer that breaks
at `‹LS›` shows the `if` on a line of its own, while the compiler reads it as
comment text:

```ipe ipe:skip a bidirectional control cannot be written safely in a Markdown page
module Gate exposing (allowed)

allowed : Bool -> Bool
allowed authorized =
    -- check‹RLO› the caller ‹LS›if authorized then True else False
    False
```

## To fix

Delete the character, or replace a separator with a real line break. Most
editors can reveal invisible characters (a "render control characters" or "show
invisibles" setting) so you can find it. The lines above then hold the code they
showed:

```ipe
module Gate exposing (allowed)

allowed : Bool -> Bool
allowed authorized =
    -- check the caller
    if authorized then True else False
```

If the character belongs in a value, keep it inside a string literal, and close
every isolate you open in that same literal and line. Text with no hazard at
all needs no change:

```ipe
module Greeting exposing (greeting)

greeting : String
greeting =
    "hello"
```
