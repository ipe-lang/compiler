# IPE-L0162: `onNavigate` is set but the Model has no `page` field

`onNavigate` turns the page a navigation resolved to into a message, so
`update` can react to it. It only runs in a routed app, whose Model has a
`page` field. Without one there is no page to hand it, so it would never be
called.

```ipe ipe:error
-- ✘ No `page` field, so `onNavigate` never fires.
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type alias Model = { count : Int }

type Msg = Navigated | NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { count = 0 }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = []
        , notFound = 0
        , onNavigate = Navigated
        }
```

Add a `page` field to route the app:

```ipe ipe:skip the added page field fix; shown without running the checker
-- ✔
type alias Model = { count : Int, page : Page }
```

Or remove `onNavigate`:

```ipe
-- ✔ An unrouted app has no navigation hook.
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Msg = NoOp

    ( { count = 0 }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg

    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = []
        , notFound = NoOp
        }
```
