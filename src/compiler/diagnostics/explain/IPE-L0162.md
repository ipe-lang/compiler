# IPE-L0162: `onNavigate` is set but the Model has no `page` field

`onNavigate` turns the page a navigation resolved to into a message, so
`update` can react to it. It only runs in a routed app, whose Model has a
`page` field. Without one there is no page to hand it, so it would never be
called.

```ipe ipe:error
type alias Model = { count : Int }

-- ✘ No `page` field, so `onNavigate` never fires.
main =
    Web.app
        { init = init
        , update = update
        , view = view
        , onNavigate = Navigated
        }
```

Add a `page` field to route the app:

```ipe ipe:skip the added `page` field fix; shown without running the checker
-- ✔
type alias Model = { count : Int, page : Page }
```

Or remove `onNavigate`:

```ipe ipe:error
-- ✔ An unrouted app has no navigation hook.
main = Web.app { init = init, update = update, view = view }
```
