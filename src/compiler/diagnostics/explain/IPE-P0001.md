# IPE-P0001: unexpected token

I was reading your code and reached a token I didn't expect here. The
grammar at this point allows only certain things, and what I found
isn't one of them — so I stopped rather than guess at what you meant.

This usually means a small piece is missing or out of order: a stray
keyword, a misplaced operator, a `)` with no matching `(`, or two
expressions sitting next to each other with nothing to join them. Look
just before the caret — the real mistake is often the token right
before the one I'm pointing at.

For example, an operator with no right-hand side leaves me expecting an
expression and finding the end of the line instead:

```ipe ipe:error
total =
    1 +

other = 2
```

Here I expected another value after `+`. Give it one:

```ipe
total =
    1 + 2
```

A doubled keyword is another common case — the second `then` has no
place to go:

```ipe ipe:error
result =
    if ready then then 1 else 0
```

Removing the extra keyword fixes it:

```ipe
ready = True

result =
    if ready then 1 else 0
```
