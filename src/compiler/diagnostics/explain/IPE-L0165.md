# IPE-L0165: the route table of `Web.pageLink` is not a top-level list of `Web.route` calls

`Web.pageLink` writes a link's `href` from its route table at compile time:
the compiler derives the table's page renderer, the same one the routed app
uses to write the address bar. It can read a table only when the first
argument names one top-level value whose body is a list of
`Web.route "<literal path>" PageConstructor` calls. An inline list, a
function parameter, a record field, or a computed list cannot be read:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage

type alias Model = { page : Page }

type Msg = NoOp

appRoutes : List (WebRoute Page)
appRoutes =
    [ Web.route "/" HomePage, Web.route "/about" AboutPage ]

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view model =
    Web.pageLink [ Web.route "/" HomePage, Web.route "/about" AboutPage ] []   -- ✘ an inline list.
        { to = AboutPage, current = model.page, label = Ui.text "About" }

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = appRoutes
        , notFound = HomePage
        }
```

The table must also hold at least one route to a custom page type. An empty
table renders no page, so it is refused too:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage

type alias Model = { count : Int }

type Msg = NoOp

linkRoutes : List (WebRoute Page)
linkRoutes =
    []   -- ✘ no route to render a page with.

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { count = 0 }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Web.pageLink linkRoutes [] { to = AboutPage, current = HomePage, label = Ui.text "About" }

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage ]
        , notFound = HomePage
        }
```

Bind the routes to one top-level name, annotated with the page type, with a
route for every page constructor, and pass that name:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = HomePage | AboutPage

type alias Model = { page : Page }

type Msg = NoOp

appRoutes : List (WebRoute Page)
appRoutes =
    [ Web.route "/" HomePage, Web.route "/about" AboutPage ]

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view model =
    Web.pageLink appRoutes [] { to = AboutPage, current = model.page, label = Ui.text "About" }   -- ✔

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = appRoutes
        , notFound = HomePage
        }
```
