# IPE-E0002: the host linker cannot open the build directory

The compiler translated your Ipe program to Rust, but stopped before building
it: the directory the build would use, or the Rust toolchain itself, lives at
a path the host linker cannot open. This is a problem with where the project
or the toolchain lives on your machine — not a mistake in your code, and not a
bug in the compiler.

The message names which directory was refused:

- **the build directory you chose** — `CARGO_TARGET_DIR`, the `[build]
  target-dir` key in `$IPE_HOME/config.toml`, or a Cargo config `target-dir`;
- **the per-user build cache** — the project path holds characters the linker
  cannot open, and the cache the compiler would build in instead does too;
- **the Rust toolchain** — the toolchain is installed under such a path.

The usual cause is the GNU linker of a `x86_64-pc-windows-gnu` toolchain. It
opens files through the Windows code page, so a path holding a non-ASCII
character (an accent, a non-Latin script) cannot be opened. The MSVC linker
and the `gnullvm` linker open any path.

What to try:

1. **Move the project to an ASCII path**, or set `CARGO_TARGET_DIR` to an
   ASCII directory you own, under your user profile — for example
   `%USERPROFILE%\ipe-target`. Never use a folder at the root of a drive such
   as `C:\ipe-target`: other accounts on the machine can write there and plant
   files the next build links and runs.
2. **Install the `x86_64-pc-windows-msvc` or `x86_64-pc-windows-gnullvm` host
   toolchain** with `rustup`; their linkers open any path.
3. When the toolchain itself is refused, move `RUSTUP_HOME` and `CARGO_HOME`
   to an ASCII directory you own, or use the MSVC host toolchain.

Your Ipe program has nothing to fix — here is a valid program that builds
once the build directory is one the linker can open:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A type-annotated variant also compiles fine:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

There is nothing to change in your source — just move the build directory and
try again:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
