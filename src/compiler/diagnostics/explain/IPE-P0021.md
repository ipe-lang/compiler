# IPE-P0021: malformed exposing list

I was reading the `exposing (...)` list — the part that says which
names a module shares — and it isn't well formed. Either it doesn't
close properly, or something inside it isn't a name I can expose.

The list holds names separated by commas, wrapped in parentheses: a
value (`main`), a type, or a type with its constructors (`Color(..)`).
You can also write a single `..` to expose everything. A trailing
comma, a missing `)`, or a token that isn't one of these breaks the
list.

A dangling comma with nothing after it is malformed:

```ipe ipe:error
module Main exposing (main, )
```

Drop the trailing comma so the list ends cleanly:

```ipe
module Main exposing (main)
```

To expose a type together with all of its constructors, use `(..)`
after the type name:

```ipe ipe:skip illustrates exposing a type with its constructors in isolation, not a runnable program here
module Color exposing (Color(..), toHex)
```
