# IPE-L0161: the `page` field of a routed app's Model is not a custom type

A Model with a `page` field makes the app routed: each path maps to a page,
and each page renders back to its path. The pages must be the constructors
of a custom type.

```ipe ipe:error
-- ✘ A `String` page cannot be matched against routes.
type alias Model = { page : String }
```

Declare the pages as a custom type:

```ipe ipe:skip the custom-type `page` field that compiles; shown without running the checker
-- ✔
type Page = HomePage | PostPage String

type alias Model = { page : Page }
```

A type alias that names a custom type is fine; a record or a primitive is
not:

```ipe ipe:error
-- ✘ A record is not a set of pages.
type alias Model = { page : { name : String } }
```
