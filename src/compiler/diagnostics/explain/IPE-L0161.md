# IPE-L0161: the `page` field of a routed app's Model is not a custom type

A Model with a `page` field makes the app routed: each path maps to a page,
and each page renders back to its path. The pages must be the constructors
of a custom type.

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type alias Model = { page : String }   -- ✘ a `String` page cannot be matched against routes.

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = "home" }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = []
        , notFound = "home"
        }
```

Declare the pages as a custom type:

```ipe ipe:skip the custom-type page field that compiles; shown without running the checker
-- ✔
type Page = HomePage | PostPage String

type alias Model = { page : Page }
```

A type alias that names a custom type is fine; a record or a primitive is
not:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type alias Model = { page : { name : String } }   -- ✘ a record is not a set of pages.

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = { name = "home" } }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = []
        , notFound = { name = "home" }
        }
```
