# IPE-N0047: this standard-library module is not available in this shape × runtime placement

Every Ipê program is placed on two independent axes. The first is its **shape** — what `view` renders: a DOM app (`web`), full-screen terminal cells (`tui`), terminal lines (`cli`), an HTTP server (`server`), or nothing at all (`script`). The shape is pinned by the head of `main`. The second is its **runtime** — where the loop runs. Only the `web` shape has a choice here: it runs either co-located with native effects (`served`, the unnamed default) or self-contained in a browser (`client`). Every other shape has one runtime.

One table decides which effect-carrying or host-dependent standard-library module is available in which placement. A native effect (a direct database, file, server, or secret) lives only where the loop is co-located with it. A browser capability lives only where there is a browser to host it. When you import a module the table does not admit for your program's placement, the compiler stops here — before any of that reaches a build that could not run it, and before a native effect could ever be shipped inside a public browser bundle.

A browser capability in a program with no browser is the clearest case. This is refused:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Tui as Tui
import Ipe.Tea.Tui.Cmd as Cmd
import Ipe.Tea.Tui.Sub as Sub
import Ipe.Ui.Tui as TuiUi
import Ipe.Browser.Clipboard as Clipboard


type alias Model =
    { count : Int }


type Msg
    = NoOp


init : () -> ( Model, Cmd Msg )
init _unit =
    ( { count = 0 }, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )


view : Model -> Screen Msg
view _model =
    TuiUi.text "hello"


subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none


main =
    Tui.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        }
```

A full-screen terminal app (`Tui.tea`) renders terminal cells, not a DOM — it
has no browser, so a browser host capability like `Ipe.Browser.Clipboard` has
nowhere to run. (A plain `script` is exempt from this particular rule: it
renders nothing at all, so there is no live surface for a browser capability to
mismatch against — the exemption covers a decoder probe or an export check
written as a script, not a live terminal app.) Browser capabilities belong to a
web app, which is hosted in a browser:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Ui as Ui
import Ipe.Tea.Web.Cmd
import Ipe.Tea.Web.Sub
import Ipe.Browser.Clipboard as Clipboard


type Page
    = HomePage


type Msg
    = NoOp


type alias Model =
    { page : Page }


init : WebReq -> ( Model, Cmd Msg )
init _req =
    ( { page = HomePage }, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )


view : Model -> Element Msg
view _model =
    Ui.text "hello"


subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none


main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage ]
        , notFound = HomePage
        }
```

A native effect in a sandboxed `client` app is a related but different case,
caught by a separate downstream gate (IPE-N0029) once the delivery runtime is
actually resolved. This diagnostic only rejects an import that the table denies
in *every* runtime a shape can carry; a `web` app's native effect import is
never flagged here, because it is sound when served even though the identical
import would be unsound once delivered as a sandboxed client — that
runtime-specific call is IPE-N0029's job, not this one. The shape-fixed case
this diagnostic also enforces is the same browser-host rule applied to every
other non-browser shape — a view-less background worker has no browser either:

```ipe ipe:error
module Main exposing (main)

import Ipe.Tea.Worker as Worker
import Ipe.Tea.Worker.Cmd as Cmd
import Ipe.Tea.Worker.Sub as Sub
import Ipe.Browser.Clipboard as Clipboard


type alias Model =
    { ticks : Int }


type Msg
    = Tick


init : () -> ( Model, Cmd Msg )
init _unit =
    ( { ticks = 0 }, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )


subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none


main =
    Worker.tea
        { init = init
        , update = update
        , subscriptions = subscriptions
        }
```

The rule in one line: what a module needs — a native host, or a browser — must
be present in your program's shape, or in every runtime a shape with a choice
can carry, or the module is not available there.
