# IPE-E0011: a file argument outside the project sources

A command was given a `.ipe` file that is not a module of the project ipe is
working on. The project is the current directory; a file argument must lie
under its `src/` or `tests/` directory, or be its `package.ipe`.

ipe never searches upward from the file for some other project: a file
compiled under another project's manifest would get that project's
capabilities and dependencies.

What to try:

1. **Change into the project that holds the file** — the directory with its
   `package.ipe` — and run the command from there. The message names that
   directory when the file's path shows it.
2. If the file is not in any project yet, run `ipe init` in a new directory and
   move it under `src/`.

A file under `src/` is a module of the project, such as `src/Main.ipe`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A module may define values beside `main`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And it may import from the standard library:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
