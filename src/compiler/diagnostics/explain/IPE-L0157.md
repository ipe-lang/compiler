# IPE-L0157: two routes have equivalent patterns but build different pages

Two route patterns are equivalent when they have the same number of segments
and, at each position, both segments are parameters or both are literals with
the same decoded text. Parameter names and types do not matter: a path is
matched segment by segment, so the first of two equivalent routes always wins
and the second can never be reached.

When equivalent routes build different pages, `ipe` cannot tell which page
you meant, so it refuses the table.

```ipe ipe:error
-- ✘ `/a/:x` and `/a/:y` match exactly the same paths.
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Page = PageA | PageB

type alias Model = { page : Page }

type Msg = NoOp

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { page = PageA }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

view : Model -> Element Msg
view _model =
    Ui.text "hello"

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/a/:x" PageA, Web.route "/a/:y" PageB ]
        , notFound = PageA
        }
```

Decoding counts: `%41` is `A`, so these two patterns are equivalent.

```ipe ipe:skip a before/after diff on one route table; the rest of the app is unchanged from above
-- ✘ `/a/%41` and `/a/A` are the same path.
routes = [ Web.route "/a/%41" PageA, Web.route "/a/A" PageB ]
```

Parameter types do not separate routes either. Give one route a distinct
literal segment instead:

```ipe ipe:skip a before/after diff on one route table; the rest of the app is unchanged from above
-- ✘ An `Int` and a `String` parameter are both one segment.
routes = [ Web.route "/post/:n" PostById, Web.route "/post/:s" PostBySlug ]

-- ✔
routes = [ Web.route "/post/:n" PostById, Web.route "/post/slug/:s" PostBySlug ]
```
