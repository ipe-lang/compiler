# IPE-L0113: constructor used as a function value

A data constructor that carries a payload can be used as a first-class
function *value* — referenced bare, or applied to fewer arguments than it
declares (a partial application) — not only applied to all of its fields at
once. The lowerer eta-expands either shape into an ordinary closure that
takes the remaining fields as parameters, the same machinery a partially
applied named function uses, so both compile and run like any other function
value.

## Bare reference

Passing `Som` itself as a function value compiles:

```ipe
import Ipe.Io as Io

type Opt a = Som a | Non

wrapAll : (Int -> Opt Int) -> Opt Int
wrapAll f = f 1

main : Task Error ()
main =
    case wrapAll Som of
        Som _ -> Io.println "some"
        Non -> Io.println "none"
```

## Partial application

`Node` declares three fields; applying it to two yields a function waiting
on the last one, exactly like a partially applied named function:

```ipe
import Ipe.Io as Io

type Tree = Leaf | Node Tree Int Tree

main : Task Error ()
main =
    let half = Node Leaf 1 in
    case half Leaf of
        Leaf -> Io.println "leaf"
        Node _ _ _ -> Io.println "node"
```

## Saturated construction

Applying a constructor to all of its fields in one call still lowers
directly, with no closure in between:

```ipe ipe:skip the fully-applied constructor that compiles; shown without running the checker
type Tree = Leaf | Node Tree Int Tree

build : Tree
build = Node Leaf 1 Leaf       -- all fields supplied: a direct construction
```

`[feature: ctor-as-function]`

This diagnostic code is reserved by the diagnostics registry; the compiler
no longer refuses a constructor used as a function value in any shape. If
you hit a case that still refuses, please tell us at
https://github.com/ipe-lang/compiler/issues.
