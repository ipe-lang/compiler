# IPE-L0118: `Web.appRouted` is not yet supported — use `Web.tea` (non-routed) for now

You used `Web.appRouted`, the URL-routing variant of the Ipe.Web
entry point. The Rust backend does not yet wire this variant — only
the non-routed `Web.tea` (with `init`, `update`, `view`, and
`subscriptions`) is supported in this milestone.

`[feature: routed-live-app]`

Replace `Web.appRouted` with `Web.tea` and remove the `routes` /
`notFound` fields from your cfg record until routing lands:

```ipe ipe:skip a fragment; `init`, `update`, `view`, and `subscriptions` are assumed from context
-- Not yet supported:
main =
    Web.appRouted
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ route "/" HomePage ]
        , notFound = NotFoundPage
        }
```

```ipe ipe:skip a fragment; `init`, `update`, `view`, and `subscriptions` are assumed from context
-- Supported now:
main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        }
```

```ipe ipe:error
-- You can still handle navigation manually inside update:
update msg model =
    case msg of
        Navigate path ->
            ( { model | page = parsePath path }, Cmd.none )
        _ ->
            ...
```

URL routing support (`Web.appRouted`) is tracked and will land in a
future milestone. If this blocks your work, please comment at
https://github.com/ipe-lang/compiler/issues.
