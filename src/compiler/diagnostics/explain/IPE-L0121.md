# IPE-L0121: `JsonDec.succeed` / `Db.Decode.succeed` constructor arity exceeds 10

`JsonDec.succeed` and `Db.Decode.succeed` lift a constructor function into a
decoder that threads it through `JsonDecP.required` / `JsonDecP.optional`
pipeline steps. The runtime's `curry1`..`curry10` helpers power this lifting;
there is no `curry11` or higher, so a constructor with more than 10 parameters
cannot be lifted.

A 3-field record decoder works fine:

```ipe ipe:skip a fragment; JsonDecP and JsonDec are assumed from context
type alias User = { name : String, age : Int, role : String }

makeUser : String -> Int -> String -> User
makeUser name age role = { name = name, age = age, role = role }

userDecoder =
    JsonDecP.required "role" JsonDec.string
        (JsonDecP.required "age" JsonDec.int
            (JsonDecP.required "name" JsonDec.string
                (JsonDec.succeed makeUser)))
```

But a constructor with 11 or more parameters exceeds the cap:

```ipe ipe:skip a fragment; JsonDecP and JsonDec are assumed from context
-- This triggers IPE-L0121 — makeBig has 11 parameters.
makeBig : String -> String -> String -> String -> String
       -> String -> String -> String -> String -> String -> String
       -> String
makeBig a b c d e f g h i j k = a ++ b ++ c ++ d ++ e ++ f ++ g ++ h ++ i ++ j ++ k

bigDecoder =
    JsonDecP.required "k" JsonDec.string
        (JsonDecP.required "j" JsonDec.string
            (JsonDecP.required "i" JsonDec.string
                (JsonDec.succeed makeBig)))  -- 11 params → IPE-L0121
```

Split the data into two smaller records, each with at most 10 fields, and
combine them with `andThen`:

```ipe ipe:skip a fragment; JsonDec, partADecoder, partBDecoder, and mergeAB are assumed from context — this is the fix, not the trigger, so it compiles
type alias PartA = { a : String, b : String, c : String, d : String, e : String }
type alias PartB = { f : String, g : String, h : String, i : String, j : String, k : String }

-- Decode each half separately, then merge.
bigDecoder =
    JsonDec.andThen
        (\a -> JsonDec.map (\b -> mergeAB a b) partBDecoder)
        partADecoder
```
