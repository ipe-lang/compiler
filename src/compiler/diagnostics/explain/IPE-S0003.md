# IPE-S0003: native Rust code is crossed without the app's grant

Your program imports a `Rust.<Crate>` module, which crosses from Ipê into
native Rust code, and the app's `package.ipe` has not granted that crossing.
Ipê cannot see what native code does: its effects are opaque to the type
checker, and the OS jail contains them only at run time. So the crossing itself
needs the consumer's consent, and I stop the build before the costly emit and
cargo steps.

The refusal names each crate crossed and the module that crosses it. A
dependency can cross, but it cannot authorise itself: only the top-level app
grants the crossing, and the grant does not compose down the tree.

## The safe path is untouched

Code that imports no `Rust.` module crosses into no native code and needs no
grant:

```ipe
import Ipe.Html exposing (text, section)

view summary =
    section [] [ text summary ]  -- pure Ipê: nothing crosses
```

## What triggers the refusal

Importing a bound crate crosses the boundary, whether your own code or a
dependency does it:

```ipe ipe:skip needs the crate declared in package.ipe, which a single fence cannot carry
import Rust.Csum as Csum

checksum bytes =
    Csum.sum bytes  -- native code runs here
```

## How to grant it

Review the crate, then declare the `NativeFfi` capability under `capabilities`
in the app's `package.ipe`. Drop the dependency instead when you do not want
the crossing at all:

```ipe ipe:skip a manifest fragment, shown for its shape
-- package.ipe
-- package =
--     { name = "my-app"
--     , capabilities = { declares = [ NativeFfi ] }
--     }
```

## A crossing that cannot be attributed

When the program crosses into native code but no scanned source can be traced
to a crate, I refuse as well and say so. A crossing I cannot attribute is
never dropped.

## Glossary

- **crossing** — a call from Ipê into native Rust code through a `Rust.<Crate>`
  import.
- **opaque** — outside what Ipê's types can describe; the crate's real effects
  are known only to the crate.
- **fail closed** — when consent is absent or cannot be traced, refuse rather
  than proceed.
