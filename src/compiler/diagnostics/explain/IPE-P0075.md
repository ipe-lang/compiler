# IPE-P0075: a triple-quoted string in neither of its two forms

A `"""` string takes one of two forms, and the compiler reads its value from
that form alone:

- **One line:** `"""text"""` opens and closes on the same line. The value is
  the text between the quotes, exactly as written.
- **Block:** the opening `"""` ends its line, and the closing `"""` stands
  alone on its own line, in the same column as the opening one. That column
  is the block's margin. The value is the lines between the two, with
  everything left of the margin removed, joined by line breaks; the line
  break before the closing `"""` is not part of the value.

A string that fits neither form is refused rather than given a guessed value.
Each shape below names its one fix.

Text after an opening `"""` that does not close on the same line:

```ipe ipe:error
greeting =
    """Hello,
    world
    """
```

Move the text to the next line. A space or tab left after the opening `"""`
is refused the same way, because it cannot be seen: remove it.

A closing `"""` that ends a line of content instead of standing alone:

```ipe ipe:error
greeting =
    """
    Hello, world"""
```

Put the closing `"""` on its own line, in the margin column.

A closing `"""` in another column than the opening one:

```ipe ipe:error
greeting =
    """
    Hello, world
        """
```

Move the closing `"""` to the column of the opening one. Both fixes give the
same block, whose value is `Hello, world`:

```ipe
greeting =
    """
    Hello, world
    """
```

A string that fits on one line keeps both quotes there, and may hold a lone
`"` in its text:

```ipe
quoted =
    """she said "hi" to them"""
```
