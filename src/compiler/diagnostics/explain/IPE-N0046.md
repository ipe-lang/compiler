# IPE-N0046: Web.tea init annotation uses a type variable where WebReq is required

`Web.tea`'s `init` function always receives a `WebReq` — the per-request
context carrying `path`, `query`, `method`, `params`, `headers`, and `cookies`.
The request type is not user-choosable: it is fixed by the runtime's HTTP layer.

When you annotate `init` with a free type variable (`a`, `req`, etc.) the
compiler still accepts the program (the variable unifies with `WebReq` at the
call site), but the emitted Rust function becomes generic (`fn init<T1: Clone>`).
A generic init:

- Cannot read `req.path`, `req.cookies`, etc. — the type variable has no
  known fields, so field access is rejected at the point where it would be
  most useful.
- Violates the make-invalid-states-unrepresentable principle: the annotation
  claims the function works for *any* request shape, which is a lie.
- Produces a misleading public signature that hides the real contract.

## Fix

Write the concrete annotation, or omit the annotation entirely:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Ui as Ui
import Ipe.Tea.Web.Cmd
import Ipe.Tea.Web.Sub


type Page
    = HomePage


type Msg
    = NoOp


type alias Model =
    { path : String }


-- Explicit and correct:
init : WebReq -> ( Model, Cmd Msg )
init req =
    ( { path = req.path }, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )


view : Model -> Element Msg
view model =
    Ui.text model.path


subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none


main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = [ Web.route "/" HomePage ]
        , notFound = HomePage
        }
```

`WebReq` from how `init` is used as `Web.tea`'s `init` field:

If you do not need the request in `init`, annotate with `WebReq` and ignore
the argument with `_`:

```ipe
module Main exposing (main)

import Ipe.Tea.Web as Web
import Ipe.Ui as Ui
import Ipe.Tea.Web.Cmd
import Ipe.Tea.Web.Sub


type Page
    = HomePage


type Msg
    = NoOp


type alias Model =
    { path : String }


defaultModel : Model
defaultModel =
    { path = "/" }


init : WebReq -> ( Model, Cmd Msg )
init _ =
    ( defaultModel, Cmd.none )


update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )

    Ui.text model.path

    Sub.none


main =
    Web.tea
        { init = init
        , update = update
        , view = view

        }
```

## Background

`WebReq` is an opaque nullary type at the type level (no bare record literal
can masquerade as the runtime struct — the same posture as the opaque server
`Request`), but its fixed field set is readable via the deferred field-access
pass. Reads lower to `(req).<field>.clone()` against `ipe_runtime::dom::req::WebReq`
directly (the canonical, target-neutral definition; also compiles on `wasm32`).

Full design: `docs/adr/0005-delivery-shapes-runtimes-hosts-targets.md`.
