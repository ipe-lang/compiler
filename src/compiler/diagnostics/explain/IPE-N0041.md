# IPE-N0041: Ipe.Codec.auto cannot derive a codec for this type

`Codec.auto` writes a record's codec for you. You give it a *witness* — a value
whose type is the record you want a codec for — and the compiler reads that
record's fields and builds the same field-by-field `Codec` you could have
written by hand:

```ipe
import Ipe.Codec as Codec exposing (Codec)


type alias User =
    { id : String, age : Int, active : Bool }


blankUser : User
blankUser =
    { id = "", age = 0, active = False }


userCodec : Codec User
userCodec =
    Codec.auto blankUser
```

The derived `userCodec` encodes and decodes exactly as a hand-written codec
would: one JSON field per record field, each read by the codec its type selects
(`String` → `Codec.string`, `Int` → `Codec.int`, and so on).

## What went wrong

`Codec.auto` was applied to something it cannot turn into a codec. There are two
families of cause.

**The witness is not an annotated record value.** `Codec.auto` reads the record
type of its argument, so the argument must be a top-level value carrying a
record-type annotation. A bare literal, a non-record value, or a value with no
type annotation gives the derive nothing to read:

```ipe ipe:error
import Ipe.Codec as Codec


-- rejected: no record type to read the fields from
userCodec =
    Codec.auto { id = "" }
```

**A field has no derivable leaf codec.** Every field's type must itself have a
codec the derive can build. These field types are refused:

- a `Secret` (or a reserved sink type) — encoding a secret to JSON or a column
  is exactly the leak the Security principle forbids, so it is *unencodable by
  construction*, never a partial codec;
- a function — not a serialisable value;
- a data-carrying ADT (a union whose constructors hold arguments), an opaque
  handle, or an effect / decoder carrier — these have no single obvious wire
  shape.

## How to fix

For a bad witness, give `Codec.auto` a value annotated with the record type:

```ipe
import Ipe.Codec as Codec exposing (Codec)


type alias User =
    { id : String, age : Int, active : Bool }


blankUser : User
blankUser =
    { id = "", age = 0, active = False }


userCodec : Codec User
userCodec =
    Codec.auto blankUser
```

For a field the derive cannot handle, write that part of the codec explicitly. A
data-carrying union has a first-class combinator — `Codec.taggedUnion` with
`var0` / `var1` / … — and any field can be given a hand-written `Codec`. Drop a
`Secret` field from the record you serialise: a secret does not belong on the
wire or in a column.

## Glossary

- **codec** — one value that bundles both an encoder (value → JSON) and a
  decoder (JSON → value), so the two directions cannot drift apart.
- **witness** — the argument you pass to `Codec.auto`; its only job is to name
  the record type, so the compiler can read that type's fields. Its runtime
  value is never inspected.
- **derive** — to have the compiler write code for you from a type's shape,
  here the field-by-field codec, rather than writing it by hand.
- **leaf codec** — the codec for one field's type, chosen from the field's type
  (`String` → `Codec.string`, `List a` → `Codec.list …`, and so on).
