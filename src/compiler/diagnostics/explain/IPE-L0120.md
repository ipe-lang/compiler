# IPE-L0120: app Model is not admissible for this app shape

The state type (the **Model**) threaded through an app entry point's
`init` / `update` / `view` must satisfy the runtime bound that app shape
requires. Your Model does not, so `ipec` rejects it here instead of letting
the generated Rust fail to compile.

* **`Ipe.Web`** persists the Model to the session store between requests, so
  the Model must be **serialisable** (`serde::Serialize` +
  `serde::de::DeserializeOwned`) as well as `Clone` and `PartialEq`.
* **`Ipe.Tui`** and **`Ipe.Webview`** keep the Model in memory, so it must be
  **clonable** (`Clone`).

A Model made of plain data (ints, floats, strings, bools, bytes, lists, tuples,
records, and your own enums of plain data) always satisfies both. The values
that are **not** admissible are effects and handles — `Cmd`, `Sub`, `Task`,
`Decoder`, `Db`, server/live request handles, and functions — and, for
`Ipe.Web` only, view values such as `Html`, `Element`, and `Color` (these are
clonable but not serialisable).

This trips the gate — the Model holds a command:

```ipe ipe:error
import Ipe.String as String
import Ipe.Tea.Cli as Cli
import Ipe.Tea.Cli.Cmd as Cmd
import Ipe.Tea.Cli.Sub as Sub
import Ipe.Ui.Cli as Ui
import Ipe.Ui.Cli exposing (Lines)

type Msg
    = NoOp

type alias Model =
    { count : Int
    , pending : Cmd Msg          -- not serialisable, not clonable
    }

init : () -> ( Model, Cmd Msg )
init _unit =
    ( { count = 0, pending = Cmd.none }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd Msg )
update _msg model =
    ( model, Cmd.none )

view : Model -> Lines Msg
view model =
    Ui.text (String.fromInt model.count)

subscriptions : Model -> Sub Msg
subscriptions _model =
    Sub.none

main =
    Cli.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        }
```

A view value in a `Ipe.Web` Model trips it too:

```ipe ipe:error
import Ipe.Html as Html exposing (Html)
import Ipe.String as String
import Ipe.Tea.Web as Web
import Ipe.Tea.Web.Cmd as Cmd
import Ipe.Tea.Web.Sub as Sub
import Ipe.Ui as Ui

type Msg
    = NoOp

type alias Model =
    { count : Int
    , cached : Html Msg          -- clonable, but not serialisable
    }

init : WebReq -> ( Model, Cmd.Cmd Msg )
init _req =
    ( { count = 0, cached = Html.text "" }, Cmd.none )

update : Msg -> Model -> ( Model, Cmd.Cmd Msg )
update _msg model =
    ( model, Cmd.none )

view : Model -> Element Msg
view model =
    Ui.text (String.fromInt model.count)

subscriptions : Model -> Sub.Sub Msg
subscriptions _model =
    Sub.none

main =
    Web.tea
        { init = init
        , update = update
        , view = view
        , subscriptions = subscriptions
        , routes = []
        , notFound = NoOp
        }
```

Keep only plain data in the Model. Compute commands in `update` and view
values in `view`; store the ingredients (the data they are derived from), not
the effect or the rendered value:

```ipe
type alias Model =
    { count : Int
    , label : String
    }
```
