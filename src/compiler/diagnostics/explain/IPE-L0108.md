# IPE-L0108: kernel function not available yet

You called a built-in (kernel) function that Ipe knows the name of but
hasn't implemented in this version. So far only a small set of kernels
is wired up — `Io.println` and `String.fromInt` — and the one you
reached for isn't connected yet.

This is a gap in the standard library, not a mistake in how you called
it. If the name is close to one I do support, I'll suggest it. Over
time many more kernels will arrive; for now, lean on the ones that are
available.

`[feature: kernels]`

Calling a kernel that isn't ready yet trips this:

```ipe ipe:skip the not-yet-wired kernel call IPE-L0108 flags; shown without running the checker
main : Task ()
main =
    Time.now
```

A misspelled kernel lands here too, with a suggestion:

```ipe ipe:skip the misspelled-kernel shape IPE-L0108 flags; shown without running the checker
greeting : String
greeting =
    String.fromInteger 42
```

The supported kernels work as expected:

```ipe
import Ipe.Io as Io
import Ipe.String as String

main : Task ()
main =
    Io.println (String.fromInt 42)
```

This is a current limitation, not an error on your part. If you need a
particular kernel function soon, tell us at
https://github.com/ipe-lang/compiler/issues so we can prioritise it.
