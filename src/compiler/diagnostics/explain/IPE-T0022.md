# IPE-T0022: this type nests too deeply

Every value has a type, and a type can hold other types: a record holds the
types of its fields, `Maybe a` holds `a`, a function holds the types of its
argument and its result. Each of those wrappings is one **level**. This error
means the type of a value has more levels than I allow — 64.

The usual source is a chain of definitions where each one wraps the one before
it. No single line is deep, but the type grows by one level per definition:

```ipe ipe:skip an outline of a long chain; the real one is 65 definitions
x0 = 0
x1 = { a = x0 }
x2 = { a = x1 }
-- … and so on, each wrapping the last …
x65 = { a = x64 }
```

The type of `x65` is a record inside a record, 65 times over. The message
names how deep the type got and the limit it passed; it never prints the type
itself, because a type that deep would fill the screen.

A custom type counts too: it is one level above the types its constructors
hold, so a chain of declarations, each holding the one before it, nests the
same way:

```ipe ipe:skip an outline of a long declaration chain; the real one is 65 types
type U0 = U0
type U1 = U1 U0
-- … and so on, each holding the last …
type U65 = U65 U64
```

A recursive custom type is not a chain: `type Tree = Leaf Int | Node Tree Tree`
is a few levels deep however large a tree grows.

## Why the limit exists

Every type turns into a Rust type when your program is compiled, and the Rust
compiler stops with an error when a type nests past its own recursion limit.
The generated crate raises that limit, and the type ceiling here keeps every
type I accept well inside it. Refusing the program now, with the place that
crossed the line, is better than a confusing failure from the Rust build.

## Right

Give the shape a name, so a value holds a known type instead of a growing one:

```ipe
type alias Point =
    { x : Int, y : Int }

origin : Point
origin =
    { x = 0, y = 0 }
```

When the data really is a long sequence, keep it in a list. A list of a
thousand records is still one level over its element type:

```ipe
points : List { x : Int, y : Int }
points =
    [ { x = 0, y = 0 }, { x = 1, y = 1 } ]
```
