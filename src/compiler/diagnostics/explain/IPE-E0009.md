# IPE-E0009: an exposed module is missing

`package.ipe` lists a module in `exposedModules`, the library's public
surface, but `src/` holds no file for it. A module name maps to one file under
`src/`: `Shapes.Circle` is `src/Shapes/Circle.ipe`.

A downstream package importing that module would fail, so the library is
refused here, where the fix is.

What to try:

1. **Create the module's file** under `src/`, at the path its name spells.
2. **Remove the name** from `exposedModules` if the module is gone or private.
3. Check the spelling: module names and file names match exactly, case
   included.

Each exposed module is an ordinary module under `src/`, written like any
other:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

A module may define values beside `main`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And it may import from other modules:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
