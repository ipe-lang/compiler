# IPE-P0022: a mobile bundle needs a Web app

You asked for a mobile bundle with `web solo <ios|android>`, and this app is not
a `Web` app. A mobile bundle hosts the app's browser client in the system
webview of an iOS or Android shell. Only an app whose program shape is `Web`,
compiled to wasm, has a browser client to host, so any other shape has nothing
to wrap and I stop before laying out a shell around an empty page.

An app with another shape runs on the host that matches that shape.

## The safe path is untouched

A `Web` app builds for every delivery it declares, mobile included. Its view
is built from the browser view library:

```ipe
import Ipe.Html exposing (text, section)

view summary =
    section [] [ text summary ]
```

## What triggers the refusal

The command names a mobile host while the entry `main` is not a `Web` program:

```ipe ipe:skip a shell command, shown for its shape
ipe dev build web solo ios
-- error: this app's shape is not `Web`
```

## How to fix it

Declare a `Web` program shape for the entry, or pick the delivery that matches
the shape the app already has:

```ipe ipe:skip a shell command, shown for its shape
ipe dev build
```

## Glossary

- **program shape** — the kind of program `main` is: a script, a terminal
  program, a command-line program, a server or a web app.
- **mobile bundle** — the iOS or Android shell project that hosts the browser
  client in a system webview.
- **fail closed** — when no browser client exists to host, refuse rather than
  write a shell that shows nothing.
