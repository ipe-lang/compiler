# IPE-P0062: malformed if expression

I was reading an `if … then … else …` expression and its shape isn't
right. In Ipe an `if` is an expression, not a statement: it always has
a condition, a `then` branch, and an `else` branch, and both branches
produce a value.

Something in that structure is missing here: perhaps the condition is
absent, the `then` keyword doesn't follow the condition, or the `else`
branch (and its `else` keyword) is missing. Every `if` needs all three
parts because the whole expression must evaluate to a value on either
outcome.

An `if` without an `else` has no value when the condition is false:

```ipe ipe:error
sign =
    if n > 0 then 1
```

Give it both branches:

```ipe
n = 5

sign =
    if n > 0 then 1 else 0
```

Chain further choices with `else if`; the final `else` is still
required:

```ipe
n = 5

sign =
    if n > 0 then
        1
    else if n < 0 then
        -1
    else
        0
```
