# IPE-E0006: a declared program entry is missing

`package.ipe` declares a program whose `entry` names a file under `src/`, but
that file does not exist. An entry is spelled relative to `src/`, with `/`
between the levels: `entry = "Cli/Main.ipe"` is the file `src/Cli/Main.ipe`.

What to try:

1. **Create the file** the entry names, under `src/`.
2. **Fix the entry** in `package.ipe` so it names a file that exists. Write it
   relative to `src/` — not `src/Cli/Main.ipe`, just `Cli/Main.ipe`.
3. Remove the program from `programs` when it is no longer built.

A program entry is an ordinary module, such as:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

The module may define values beside `main`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And it may import from the standard library:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
