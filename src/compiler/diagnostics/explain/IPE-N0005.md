# IPE-N0005: module has no such member

The module part of your qualified name is fine — I found the module — but it does not have a member with the name you asked for. Either that name does not exist in the module, or it exists but the module does not expose it. So `String.frobnicate` fails here because `String` has no `frobnicate`.

This is most often a spelling slip on the member name. If the module has a member with a similar name, I will suggest it. If you are sure the member should be there, double-check that it is exported by the module.

Here a member of a known module is misspelled:

```ipe ipe:error
import Ipe.String

label : String
label = String.frobnicate 42
```

`String` has no `frobnicate`. You almost certainly meant `fromInt`:

```ipe
import Ipe.String

label : String
label = String.fromInt 42
```

When you have the right module and the right member name, the qualified call resolves cleanly:

```ipe
import Ipe.String

shouted : String
shouted = String.toUpper "hello"
```
