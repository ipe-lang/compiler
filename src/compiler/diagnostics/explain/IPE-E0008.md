# IPE-E0008: a program entry passes through a symbolic link

A program `entry` in `package.ipe` is reached through a symbolic link under
`src/`: the entry file itself, or a directory on the way to it, is a link.

ipe opens every level of a project without following links. A link can point
anywhere — out of `src/`, out of the project, into another user's files — so the
module ipe compiled would no longer be the file the project holds. The entry is
refused rather than followed.

What to try:

1. **Replace the link with the real file or directory**, inside `src/`.
2. If the code is shared with another project, depend on it as a package
   instead of linking it in.

A program entry is an ordinary module inside `src/`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

main : Task ()
main =
    Io.println "hello"
```

It may define values beside `main`:

```ipe
module Main exposing (main)

import Ipe.Io as Io

greeting : String
greeting = "hello"

main : Task ()
main =
    Io.println greeting
```

And it may import from the standard library:

```ipe
module Main exposing (main)

import Ipe.Io as Io
import Ipe.String as String

count : Int
count = 41 + 1

main : Task ()
main =
    Io.println (String.fromInt count)
```
