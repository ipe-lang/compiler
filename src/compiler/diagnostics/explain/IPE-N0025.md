# IPE-N0025: reserved namespace

A local module's name begins with `Ipe` or `Std`, which are namespaces reserved for the Ipe standard library and runtime. User modules must use a different first segment.

A module trying to claim a reserved namespace:

```ipe ipe:error
module Ipe.Extra exposing (helper)
helper = "extended!"
```

This is rejected because `Ipe` is reserved. Rename your module:

```ipe
module App.Extra exposing (helper)
helper = "extended!"
```

The restriction applies to the first path segment only. `MyApp.Ipe` or `Data.Std` are fine. Only modules whose first segment is exactly `Ipe` or `Std` are rejected.

This rule exists to prevent local modules from silently shadowing stdlib modules. If a local `Std.Log` were allowed, every file that `import Std.Log` would import your local file instead of the stdlib logger, producing confusing type errors or silent misbehaviour.

Once the module is renamed, import it from your entry point as usual:

```ipe ipe:skip illustrates importing a renamed module from a second file; the checker compiles one module and cannot construct a multi-file project
module Main exposing (main)
import App.Extra as Extra

main = println Extra.helper
```
