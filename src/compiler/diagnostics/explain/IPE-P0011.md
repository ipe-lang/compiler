# IPE-P0011: stray '.'

I ran into a `.` standing on its own, where I expected a name on one or
both sides of it. In Ipe a dot joins two names together — a module to
one of its values (`String.length`) or a record to one of its fields
(`user.name`) — so it can't float free.

Check what sits immediately around the dot. There must be a name with
no space before it and a name with no space after it. A gap on either
side, or a dot where you meant something else (like the `..` range or
the `..` in an `exposing (..)` list), produces this error.

A space after the dot breaks the join:

```ipe ipe:error
length =
    String. length text
```

Close the gap so the two names read as one path:

```ipe
import Ipe.String as String

text = "hello"

length =
    String.length text
```

A trailing dot with nothing after it is also stray:

```ipe ipe:error
field =
    user.
```

Name the field you actually want:

```ipe
user = { name = "Ada" }

field =
    user.name
```
