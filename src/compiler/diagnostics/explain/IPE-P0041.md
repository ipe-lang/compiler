# IPE-P0041: expected a type

I was reading a type — after a `:` in a signature, inside a `->` arrow,
or as an argument to another type — and I reached a spot where a type
should be, but found something that can't be one.

A type is a constructor (`Int`, `String`, `List`), a type variable
(`a`), a record (`{ x : Int }`), a function arrow (`Int -> Int`), or
any of these in parentheses. A keyword, an operator, or a closing
bracket in that position isn't a type, so I stop. Check what sits right
after the caret — that's where the type was meant to go.

An arrow with nothing after it leaves the result type missing:

```ipe ipe:error
double : Int ->
42
```

Name the type the function returns:

```ipe
double : Int -> Int
double n =
    n
```

Each argument position needs a type too, not a gap:

```ipe
add : Int -> Int -> Int
add a b =
    a + b
```
