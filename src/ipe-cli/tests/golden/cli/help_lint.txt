  ipe lint [<path>]

  Arguments:
    A module file of this project, whose findings alone are reported and fixed, or a project directory. Defaults to the current directory's project, every module.

    [--fix]    apply every machine-applicable (semantics-preserving) fix instead of only reporting

    [--plain]  print one finding per line flush-left (rule:file:line:col: message), no decoration
