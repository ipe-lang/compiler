  Ipê language - v<VERSION> - https://github.com/ipe-lang/compiler

  Report the security capabilities a program exercises, inferred from its code.

  ipe capabilities [<path>]

  Arguments:
    A project directory, its package.ipe, or one of its entry files under `src/`; a file must lie in the current directory's project. Defaults to the current directory's project, every entry.

  Options:
    [--plain]  print the bare capability names, one per line, flush-left
    [--json]   print the capability set as a stable JSON envelope for jq
