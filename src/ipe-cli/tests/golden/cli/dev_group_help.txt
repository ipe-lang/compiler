  Ipê language - v<VERSION> - https://github.com/ipe-lang/compiler

  The development inner loop — build, run, and watch with Debug.* on and no jail.

  `ipe dev` runs your program with your full user permissions and checks no capabilities. Run external packages only through `ipe release`, which infers capabilities, asks for consent and runs native code jailed.

  ipe dev <verb>

  Verbs:
    ipe dev build  Compile a program to a native or WebAssembly development artifact, with Debug.* on.
    ipe dev run    Compile a program as a development build and run the resulting binary.
    ipe dev watch  Rebuild and re-run a development build on every source change.
